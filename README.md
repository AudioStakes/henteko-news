# へんてこニュース

5歳以上の子ども向けのおふざけ言葉ゲームです。
「だれが、いつ、どこで、なにを、どうした」を順番に選ぶと、へんてこなニュースが完成します。
オレンジ色の絵本のような画面で、ひよこのニュースキャスターと遊べます。
スマートフォンでもパソコンでも、アカウント登録なしで遊べます。

## 遊び方

1. 「はじめる」を押します。
2. 各質問の5つの選択肢から1つずつ、5回言葉を選びます。
3. 音声を利用できる環境では、完成したニュースを自動で読み上げます。「きく」で読み上げをもう一度聞けます。
4. 「つぎをつくる」で新しいニュースを作ります。

音声設定は画面上部の「おとな」から開けます。
音声が使えない環境でも、文字だけで最後まで遊べます。
標準の読み上げにはブラウザーの音声機能を使うため、モデルのダウンロードやAPIキーは不要です。
日本語の声と音声の利用可否は端末やブラウザーの設定に依存します。

## 技術構成

ゲームはブラウザー内で動作し、Netlifyから静的ファイルとして配信します。

| 用途           | 使用技術                                           |
| -------------- | -------------------------------------------------- |
| 画面と状態管理 | React 19、TypeScript 7、CSS                        |
| 開発と配信     | Vite 8、Netlify、PWA（Service Worker）             |
| 読み上げ       | Web Speech API、任意でSupertonicとONNX Runtime Web |
| 検証           | Vitest、Testing Library、Playwright、Biome、ESLint |

ゲーム進行と読み上げの状態はアプリケーション層にまとめ、画面の表示と分けています。

PWAでオフライン時の文字のゲームにも対応しています。
音声モデルとWASMランタイムは事前キャッシュの対象外です。

型チェック、静的解析、単体テスト、本番ビルドを `npm run validate` にまとめています。
設計や検証の詳細は[開発ドキュメント](docs/DEVELOPMENT.md)にまとめています。
過去の公開版の確認結果は[検証記録](docs/release-verification.md)を参照してください。

## ローカルで動かす

Node.js 24系を使用します。
このリポジトリを取得して、次のコマンドを実行します。

```sh
npm ci
npm run dev
```

モデル音声の設定、検証、デプロイの手順は[開発ドキュメント](docs/DEVELOPMENT.md)を参照してください。
変更を提案する場合は[開発への参加](CONTRIBUTING.md)も確認してください。
