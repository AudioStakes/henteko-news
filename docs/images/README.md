## 撮影条件

- Node.js 24.18.0、Playwright 1.64.1、Chromium 156.0.8078.4。
- 画面幅390px・高さ844px、表示倍率1、`deviceScaleFactor: 1`、`reducedMotion: "reduce"`。
- フォントと画像の読み込み後に、ページ全体を撮影。画像3枚とも390×931pxです。
- 音声設定はSupertonicを選択し、実際の音声再生中（`speech.phase = "speaking"`）に完成画面を保存しました。アプリの標準設定はブラウザー音声です。
- 5段階の選択、読み上げの開始と終了、終了後の「きく」の有効化を確認し、ページの実行時例外は0件でした。

撮影したニュースは「ネコが／クリスマスのあさ／おしいれで／ピザを／まねしました！」です。
選択肢は通常のシャッフル結果から選ぶため、再撮影すると文面は変わります。

## 撮り直すとき

```sh
npm ci
npm run setup:speech
npm run build
npm run preview -- --host 127.0.0.1 --port 4176 --strictPort
```

1. `http://127.0.0.1:4176/` を新しいブラウザープロファイルで開き、上記の画面サイズでトップ画面を保存します。
2. 「おとな」から読み上げ方式をSupertonicへ変更して保存します。
3. 「はじめる」で進み、5候補の選択画面を保存します。
4. 5つの質問に答え、「よんでいるよ」と原稿を読むひよこが表示されている間に完成画面を保存します。
5. 画像を更新したら、READMEの説明・alt・この記録も撮影内容に合わせます。
