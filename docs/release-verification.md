## 修正した動作

| 対象               | 修正内容                                                                      |
| ------------------ | ----------------------------------------------------------------------------- |
| 小さい画面と横向き | 選択肢の操作領域を確保し、必要な画面ではスクロールして全文を読めるようにする  |
| キーボード操作     | 各質問と結果へフォーカスを移し、設定ダイアログから元の操作へ戻れるようにする  |
| 表示の読みやすさ   | 主要ボタンの文字色と背景のコントラストを改善する                              |
| オフライン起動     | ビルド後のJSとCSSを事前保存し、保存したHTMLと同じ版のファイルを使う           |
| 音声確認           | 音声エラー後に、失敗した語から再開できるようにする                            |
| モデル音声の再試行 | タイムアウトした読み込みを次の試行と分け、遅れて完了した処理の資源を解放する  |
| 開発環境           | Node 24と型定義を揃え、検証ツールを固定し、開発用依存の既知の脆弱性を修正する |
| 公開情報           | 利用者向けREADME、技術構成、画像の出所、MITライセンス、Netlify設定を整える    |

ONNXの読み込みと推論は、現在のAPI構成では実行途中に強制停止できません。
キャンセルした要求は結果を使わず、処理が終了した時点で不要なセッションを解放します。

## 検証環境と結果

Node 24.18.0とPlaywright 1.64.0を使いました。
`npm run validate` では単体テスト164件とNodeスクリプトテスト29件、型チェック、静的解析、本番ビルドが成功しました。

| 環境                             | 結果     |
| -------------------------------- | -------- |
| デスクトップ Chromium            | 22件成功 |
| デスクトップ Firefox             | 22件成功 |
| デスクトップ WebKit              | 22件成功 |
| Android相当（Pixel 7、Chromium） | 22件成功 |
| iPhone相当（iPhone 13、WebKit）  | 22件成功 |
| iPad相当（第7世代、WebKit）      | 22件成功 |

合計132件が成功し、失敗、スキップ、不安定な再試行は0件でした。
ゲームの5段階と再開、キーボード操作、設定の保存と入力検証、フォーカス復帰、オフライン起動、接続の切り替え、PWAの素材を検証しています。
画面サイズには幅320px、横向き667×375pxと844×390px、低いデスクトップ画面、スクロール切り替えの境界621pxを含めました。

Firefoxのネットワークエミュレーションでは、オフラインで再読み込みした後にオンラインイベントが届かない挙動を確認しました。
このケースは実通信の成功とオンラインでの再読み込みを確認し、再読み込みを挟まない接続切り替えは別テストで確認しています。
合成した接続イベントで結果を補っていません。

通常のE2Eでは音声を固定したモックに置き換え、画面進行とエラー処理を検証します。
これとは別に、固定リビジョンのSupertonicモデルを使うChromiumのテスト1件も成功しました。
本番ビルドから44.1kHzのPCM WAVを生成し、音量のピークが0より大きいことを確認しています。

スマートフォンとタブレットはPlaywrightのエミュレーションを使います。
物理端末での操作、日本語の声の提供状況、OSごとの音声品質は、この検証だけでは確認できません。
