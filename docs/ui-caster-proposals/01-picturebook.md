# ペラの まどニュース

案名は「ペラの まどニュース」。キャスターは「ペラ」。遊び心地は「わたしが えらぶ。ペラが よむ」。子どもがことばを決め、ペラはどんな組み合わせも同じ真剣さで届ける。この役割分担が、自分の選択と聞こえてくる文を結び付ける、という仮説を置く。

ペラは、クリーム色の紙を一筆で切ったような、薄くて四角いひと。頭の右上だけが斜めに欠け、耳も髪も服もない。黒緑の二つの点の目、朱色の短い口、しおりのように細い両腕が特徴。線の揺れと左右の不揃いだけで手触りを作り、影や紙の写実的な質感は付けない。物静かで、へんてこな文にも驚きすぎず、少し首をかしげて読む。笑いの評価や大げさな成功演出はしない。

開始時は、大きな一つの穴の上縁からペラが胸までのぞき、「ことばを 5つ えらんで ニュースを つくろう」と「はじめる」を見せる。押すと前の選択と音声エラーを消し、「だれが」へ。ペラは問いの左の小さなのぞき口へ移り、以後の五段階では位置を変えない。問いと五つの進行印は上部にまとめ、その下に五候補を上二つ、中央一つ、下二つで置く。同じ段階では候補と位置を固定する。

一つ押すと、その穴の縁が白く太くなり、丸印が付く。同時に上の進行印が一つ埋まり、ペラの片手がその印へ向く。これは受理の短い合図で、演技の終了を待たず自動で次へ進む。指が離れる前の連打は次段階に渡さない。「いつ」「どこで」「なにを」「どうした」も同じ仕組みで、候補の顔色やペラの態度で選択を誘導しない。

五回目の直後、五つの穴を一つの大きな原稿窓に置き換え、完成全文を一度に表示する。ペラはこの窓の上縁から顔を出し、両手で縁をつかむ。片手の先は文字のない左余白に添える。口から窓へ短い朱色の線がつながり、この窓のことばをペラが声にしている関係を作る。窓は吹き出しにも読めるが、文章は中央の飾りではなく、左揃えの原稿として扱う。「ペラの ニュース」「じゅんび中」を添え、全文を表示したまま自動読み上げへ進む。

「ニュースです」に続き、五つのまとまりを順に読む。標準の日本語読み上げを使う想定で成立させ、声の追加制作や厳密な口パクを求めない。準備中は閉じた口と「じゅんび中」、実際の音声開始後は開いた口と「ペラが よんでいるよ」に変える。短い口の開閉は任意で、目線を原稿へ落とした静止姿勢だけでもよい。終了・停止では口を閉じ「よみおわり」または「とまったよ」。再生の「きく」は同じ導入と全文を繰り返し、処理中の二重起動を防ぐ。「もういちど」はいつでも前の声と演技を止め、新しい五候補で最初へ戻す。

音声失敗・非対応ではペラを困り顔にせず、「こえが でなかったよ。ニュースは できたよ」を一度だけ表示する。再試行可能なら「きく」を戻し、全文と次ゲームを保つ。音なしでも進行印、受理の輪郭、全文、状態文字で一巡を理解できる構成にする。動きを減らす設定では移動や口の反復を使わず、同じ位置の静止ポーズを切り替える。準備が長引いても話す演技は始めず、遅れた音声処理が次ゲームへ戻らないことを条件とする。

配色は五色。バター色 #F4E39A が地、黒緑 #193F3A が穴・地の上の文字、生成り #FFFDF3 が穴内の文字とペラ、朱 #C64B38 が口と受理の小印、青 #2B6280 が進行の補助。色だけに頼らず形とラベルを併用する。文字を第一、穴を第二、顔を第三に置き、キャラクターの頭は高さ約48pxを起点とする。問い28px、候補22px、全文26px程度の水平な日本語ゴシックを基準にし、顔を大きくするために文字を縮めない。

残すのは不揃いな穴、2・1・2のリズム、全文を包む一つの大窓、平らな色面。変えるのは強いレモン色を少し静かな地色にする点と、大窓の上縁をキャスターの居場所にする点。ペラ専用の舞台やニュース机を足さず、穴そのものを「選ぶ入口」から「声の出る原稿窓」へ読み替える。

長い候補は省略せず穴の高さを伸ばし、長い全文は語のまとまりを保って折り返す。320px幅で五候補をすべて配置し、標準的な縦画面では一画面に収めることを目指すが、極端な長語・低い横画面では縦スクロールを許す。「全候補・全文を最初から表示する」と「常に一画面に収める」を混同しない。結果窓の下に二操作を置き、顔の固定表示や重ねる操作バーで文を覆わない。候補は高さ80pxを起点、44pxを下限とし、穴の外にも間隔を確保。読み順を上左・上右・中央・下左・下右に揃え、見えるフォーカス、新しい問いへの移動、セーフエリアを保つ。

U・Gは一タップの五段階と役割分担、Wは全364語と短い候補／助詞付き全文／読み／丁寧な過去形の保持、Sは音声に従う演技で対応する。全語の絵は作らず、文字の難しい子には問いの印と保護者の読み添えを残す。Cは「おとな」の別導線に方式・モデルフォルダー・声JSONを置き、保存時のみ適用、取消・Escapeで破棄、入力と取得のエラーを分ける。設定中は背景操作を止め、閉じると入口へ戻し、ゲーム状態を保持する。

Aは可変高と音に依存しない表示、P・Oは初回保存後の文字ゲームのオフライン、PWA・更新・公開・許諾・解析条件を維持する。ペラは少数の静止素材で足り、画像失敗でも操作を残す。Dの全語音声確認と指定結果の導線は子どもの一巡へ入れない。Vでは読みの習熟度×音の有無、長文、小画面、キーボード、対象ブラウザーと実機を分けて確認する。

自己批評では、初案の「選んだ穴からペラが顔を出す」が、その穴を正解のように見せ、候補を覆う危険を見つけた。最終案は選択中の居場所を共通のぞき口へ固定し、完成時だけ大窓の縁へ移した。それでも、顔から文への線が「声の主」を伝えるか、中央候補へ注意が偏るか、静止画で読む役と分かるかは未検証。実装・音声・実機・対象児の確認は未実施であり、以上は試作前の仮説である。

## 静止イメージ指示

スマホ二枚を横並びにした、仕掛け絵本のような平面UI。地はバター色、穴は黒緑、文字は生成り、朱と青を小さく添える。影、紙の写真、立体カードは使わない。キャスターのペラは、右上が斜めに欠けた生成りの四角い紙のひと。点の目、朱の短い口、細い帯の両腕を持つ。左は問い「だれが？」の左の小さなのぞき口から胸まで出し、五候補を覆わない。黒緑の不揃いな穴を2・1・2に置き、ねこ、いぬ、うさぎ、おばけ、ロボットの全五候補を水平な大文字で示す。右は同じペラが大窓の上縁を両手でつかみ、原稿へ目を向けて開口。口から窓へ短い朱線。窓内に「ねこが／きのう／こうえんで／りんごを／たべました！」を斜線なしで五行すべて表示。下に「ペラが よんでいるよ」「きく」「もういちど」。顔より全文を大きく見せる。
