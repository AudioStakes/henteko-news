# ぺこの ほうそうまど

## 案名とキャラクター、遊び心地

案名は「ぺこの ほうそうまど」。キャスターは紙人形の「ぺこ」。遊び心地は「わたしが選んだことばを、目の前の人がニュースにして届ける」。子どもはことば係、ぺこは放送係です。読み手の姿と、その人が見ている原稿を同じ舞台に置けば、標準の読み上げでも声の主を結び付けやすい、という仮説です。

ぺこは角を切った四角い顔、短い横髪、小さな丸い目、幅広の手を持つ紙人形。深緑のベストと蝶ネクタイを着ています。うれしくても大騒ぎせず、どんなへんてこな文も大切なお知らせとして読む性格。子どもの選択を採点せず、読む役に徹します。顔と手は平らな色面で描き、立体感や細かな表情に頼りません。

## 一巡と演技

開始では舞台上辺からぺこが胸まで見え、片手を開いて「ことばを 5つ えらぼう」と「はじめる」を案内します。登場を待つ演出や紹介操作はありません。開始で前の選択と音声エラーを消します。

選択では「だれが→いつ→どこで→なにを→どうした」の順を固定し、各段階の重複しない無作為な5候補を、同じ段階では位置ごと固定します。ぺこは問いの左の小窓に収まり、口を閉じて問いへ目を向けます。子どもが決める間は何も催促しません。候補を押すと太い縁と丸印で受理を示し、そのまま次へ。指が離れる前の連打や同時操作は一つだけ採用し、古い選択の遅延処理を持ち越しません。進行は済んだ丸・現在の太枠・残りの細枠で区別します。

5回目で大きな原稿窓と完成全文を即座に表示します。例は「ねこが／きのう／こうえんで／りんごを／たべました！」。実画面にスラッシュは入れません。ぺこは窓上辺へ移り、片手で縁を持ち、もう片手を原稿へ開きます。声の準備中は口を閉じ、目は正面。「こえの じゅんび」を添えます。実際の再生開始で目を原稿へ下げ、口を少し開いた読むポーズに替え、「ぺこが よんでいるよ」を表示。「ニュースです」に続き5つのまとまりを順に読みます。口パクや語ごとの指差しは不要です。

読み終わると口を閉じ、顔を子どもへ戻して「よみおわり」。間を置かせず「もういちど」を押せます。「きく」は同じ原稿を再生し、再生中は重複起動を抑えます。「もういちど」は声と読むポーズを止め、選択を消して候補を再抽選し「だれが」へ戻ります。停止・失敗・画面終了・音声設定の適用時も古い演技を解除し、遅れた音声処理で復帰させません。音声イベントが欠けても待機や読む状態を永久に残さない設計とします。

## スマホの構図

選択の主役は5つの穴。ぺこを置くために候補の文字を縮めず、問いと並ぶ小さな横帯に収めます。穴は上2・中央1・下2。完成では一つの大窓に全文を置き、その上辺の手と下向きの視線で「この原稿を読む人」を示します。本文上に顔・手・字幕を重ねません。操作は原稿の後に続き、全文は読み上げ前から読め、長い場合は縦スクロールできます。

┌─────────────────┐         ┌─────────────────┐
│ おとな   ● □ □ □ □ │         │ おとな     5 / 5  │
│ [ぺこ]  だれが？     │         │ ニュースが できた  │

## 色と文字、例外への対応

配色は5色。麦色 #F4D85B を舞台、濃紺 #203C50 を穴と外側の文字、生成り #FFF8E7 を穴内の文字と顔、深緑 #447A68 を服、朱 #C7483C を口と小さな放送印に使います。状態は色だけに頼りません。日本語ゴシックを水平に組み、問い28px、候補22px、全文26pxを起点に調整します。優先順位は候補・全文、問いと操作、ぺこの順です。

長い候補は穴を縦に伸ばし、折り返して省略しません。320px幅でも2・1・2の読み順と操作順を揃え、低い横画面ではページ全体を縦に送れます。タッチ領域は高さ80pxを起点とし、44pxを下回らず、隣との間を空けます。セーフエリア、キーボードの見える枠、新しい問いと完成へのフォーカス移動を確保します。364語の専用絵は作らず、絵のない語も同じ穴と文字で扱います。五つの問いの共通マークを添えますが、語の意味を読めない場合の読み添えは保護者に残ります。

音なしでも全文・手・視線・状態表示で進行を確認できます。動きを減らす設定ではポーズを即座に切り替えるだけ。音声失敗は閉じた口と「こえが でなかったよ。ニュースは できたよ」を一度だけ表示し、全文と主要操作を残します。再試行可能なら「きく」を使えます。人形画像が欠けても文字と操作は成立させます。

## ベースの継承、要件、見直し

不揃いな穴、平らな色面、文字の主役感は残します。レモン色と紫は麦色と紺へ替え、完成窓の上辺を人形が持つ舞台枠へ変えました。穴が単なる背景で終わらず、子どものことばを放送する場所になることを狙います。

U・Gは一タップの5段階と繰り返し、Wは全364語・助詞・読み・丁寧な過去形と全文到達、Sは標準の日本語音声と任意のSupertonic、待機と再生の区別で対応。Cの保存時適用・取消・復元・入力検証は「おとな」のスクロール可能な設定内に保ち、ゲームを保持し背景操作を止め、閉じると入口へ戻します。Aは可変高・音に頼らない表示・フォーカスで対応。P・Oのオフライン文字ゲーム、PWA更新、解析・通信説明・許諾・公開条件は維持し、人形を新しい通信必須素材にしません。Dの音声確認とデバッグは通常の遊びから分けます。

自案を批判すると、手を動かして行を追う演技は、音声とずれると読む印象を壊し、本文も隠します。そこで手は窓の縁に固定し、視線と二つの静止ポーズだけに修正しました。残る弱点は、小さなぺこの視線を子どもが読み取れるかです。Vでは読みの習熟度と音の有無を分け、誰が読むと思ったか、5候補を見渡せるか、誤タップ、完成時の反応を観察します。長語・全長文、音声失敗、初回保存後のオフラインも確認し、対象ブラウザーの検証と実機の聞こえ方を分けます。効果はすべて未検証です。

## 静止イメージ指示

スマホ2枚を白い余白の上に横並びで描く。平らな麦色の舞台に濃紺の少し不揃いな穴、生成りの水平な大文字。左は「だれが？」と進行1/5、穴を上2・中央1・下2に並べ、ねこ・いぬ・うさぎ・おばけ・ロボットの5候補を必ず全部見せる。問いの左の小窓に、角を切った四角い顔、短い横髪、深緑のベストと蝶ネクタイの紙人形「ぺこ」。口は閉じ、問いへ視線を向ける。右も同じぺこを大きな原稿窓の上辺に置き、片手で縁を持ち、もう片手を窓へ開く。目は全文へ、口は少し開き「ぺこが よんでいるよ」。窓内に「ねこが／きのう／こうえんで／りんごを／たべました！」を5行で全文表示し、スラッシュは描かない。顔や手で文字を隠さず、下に「きく」「もういちど」。朱色は口と放送印だけ。紙の切り口は簡潔にし、リアルな陰影や細かな道具、吹き出しは足さない。
