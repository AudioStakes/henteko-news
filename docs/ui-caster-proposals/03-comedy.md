# もぐ平の あなニュース

キャラクターはモグラの「もぐ平」。遊び心地は「へんなニュースも、いつもの顔で読んでくれる」。子どもがことばを決め、もぐ平が伝える関係です。

丸い頭、短い手、丸眼鏡、朱色の蝶ネクタイ。小さな目と横一文字の口。記事を疑わず、背筋を伸ばして読みます。「こうえんで りんごを たべました！」にも大事件と同じ態度を保つことで、子どもが発見するおかしさが生まれる、という仮説です。

開始では上の小穴から顔と手を出し、「ことばを 5つ えらんで ニュースを つくろう」と「はじめる」を表示。タップで前の選択と音声エラーを消します。以後は「だれが→いつ→どこで→なにを→どうした」。重複のない無作為の5候補は段階中に動かしません。選んだ穴に白い太枠と丸印が付き、即座に次の問いへ。もぐ平は話しかけず、手元で待ちます。5つ目を押すと全文が一度に現れ、「ニュースです。」から自動読み上げ。「きく」で同じ導入と全文を再生し、「もういちど」で前の声と演技を止め、再抽選して最初へ戻ります。

キャスターは上端の高さ64px程度。選択は上2・中央1・下2、完成は一つの大窓。細い机の下に記事が続き、机上のマイクと「もぐ平」の名札で声の主を示します。

```text
選択中
┌─────────────────┐
│（もぐ平）       おとな│
│   ● ○ ○ ○ ○   1/5│
│       だれが？       │
│ 〔ねこ〕   〔いぬ〕  │
│      〔うさぎ〕     │
│〔おばけ〕〔ロボット〕│
└─────────────────┘
読み上げ中
┌─────────────────┐
│（もぐ平）●よんでいるよ│
│ ──もぐ平のニュース── │
│╭────────────────╮│
││ ねこが             ││
││ きのう             ││
││ こうえんで         ││
││ りんごを           ││
││ たべました！       ││
│╰────────────────╯│
│〔♪きく〕〔もういちど〕│
└─────────────────┘
```

背景はバター色 #F7E684、穴と濃い文字は濃紫 #312440、穴内の文字・顔・受理枠は生成り #FFF9EC。朱色 #D74B3Bを蝶ネクタイと放送ランプ、青緑 #266359を進行済みの印に使う5色です。色だけに頼らず輪郭と文言も変えます。水平な日本語ゴシックで問い28px、候補22px、本文26pxを起点とし、優先順位は本文・候補、操作、キャスターの順です。

音声準備中は口を閉じて原稿に手を置き、「こえの じゅんび中」。実際の再生開始で口を少し開け、一度だけ姿勢を正して「よんでいるよ」に変えます。口パク同期は不要。標準音声でも、全文を見る目線と開始・終了の姿勢で読む役を伝えます。終了・停止で口とランプを戻し、重複起動を防いだ「きく」を再び使えるようにします。失敗・非対応時は一度だけ理由と「もじで あそべるよ」を示し、全文と次ゲームを保ち、可能なら再試行。遅れた音声やイベント欠落でも古い演技を残しません。音なしでも全文、状態語、受理印で進められ、動きを減らす設定では静止姿勢だけにします。

ベースの色面、不揃いな穴、文字の主役感を残し、黄色と見出しの高さを抑えます。見直しでは、毎回のうなずきは選択を急かし、大きな机は文章を圧迫すると判断。選択中の演技をなくし、机を細い線に縮めました。前口上、突っ込み待ち、得点、報酬は足しません。

長い候補は穴を縦に伸ばして折り返し、省略しません。全364語の絵は作らず、問いマークと進行で補助し、難しい語は保護者が読み添えます。完成文は語のまとまりを保ち、最初から全文を置いて縦スクロール。小画面ではキャスターも操作も本文に重ねず、上へ流します。候補は高さ80pxを起点、最低44pxと間隔を守り、最初の一押しだけ受理して連打を次段階に持ち越しません。

U・Gは登録不要、一タップ進行と評価のない一巡で対応。Wは364語、助詞付き表記、読み、丁寧な過去形と「！」、検証条件を維持。Sは標準音声と任意のSupertonicを保ち、勝手に切り替えず、設定変更・終了時も旧音声を停止。Cは「おとな」に音声方式・モデル・声JSONを隔離。ゲームを保持し、保存時だけ適用、取消・閉じる・Escapeは破棄。復元・パス検証・取得エラー・保存不可の扱いを維持します。設定はスクロール可能で背景操作を止め、閉じると入口へ戻します。

Aは320px幅、低い横画面、タブレット・PCでも全文と操作へ到達させ、セーフエリア、キーボード、見えるフォーカス、新しい問いと完成への案内を保ちます。P・Oは初回保存後の文字ゲームのオフライン、復帰表示、PWA・更新・静的配信、解析の限定と情報非送信、通信説明・許諾・メタ情報を維持。キャスターは保存可能な少数素材とし、画像がなくても進めます。Dの全語音声確認と指定結果の導線は遊びから分離します。

弱点は、小さな表情が伝わらない可能性と、中央の穴への偏り。Vでは読みの習熟度×音の有無で、声の主の理解、全文の発見、誤タップ、再び聞く意欲を観察。音声失敗・非対応・オフラインの一巡、各設定と対象ブラウザー、実機の冒頭音声も確認します。実装時にvalidateと関連E2Eを行い、効果は観察まで断定しません。
