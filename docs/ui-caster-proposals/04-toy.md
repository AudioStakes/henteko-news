## 第2稿 おおぐちニュース

案名は「おおぐちニュース」。およみロボ「パコ」を、画面の窓そのものが口になる音読のおもちゃへ作り直す。遊び心地は「えらんだ ことばが、パコの おおきな こえになる」。子どもはニュースの作者、パコはその原稿を預かるキャスター。どんな内容も、気取って丁寧に読む性格を引き継ぐ。役割と楽しさが伝わるかは、試作後に確認する仮説である。

### 姿と役割

パコは冷たい青灰色の、平たい四角い箱。上端の大きな二つの目と、下に開く角ばった大口だけで顔をつくる。残す機械らしさは、スピーカーを思わせる「箱いっぱいの口」一つ。口の暗い空洞が、そのまま白い文字を読む窓になる。小さい頭、手足、アンテナ、計器は付けない。顔を横に添えるのでなく、問いと完成文がパコの口から出てくる構図にする。

口は歯や舌のない四角い開口部で、食べる表情には寄せない。目は完成文へ少し下向き。内容を受け取って眺め、それから堂々と読む。声色や独自のせりふを増やさず、標準音声でも「この箱が、ここにある文を読んでいる」と分かることを狙う。

### 一巡

開始では横長のパコの口に「ことばを 5つ えらぼう」、下に「はじめる」を置く。開始で前の選択と音声エラーを消す。選択中は小さな口に「だれが？」など現在の問いを置き、その下の朱赤の面に5つの候補穴を広げる。パコは黙って選択を待ち、未完成文は読まない。

各段階で重複のない無作為の5候補を示し、同じ段階では位置も内容も固定する。「だれが→いつ→どこで→なにを→どうした」の順に一つタップすると、穴の白い太枠と丸印で受理を示し、すぐ次へ進む。連打や同時操作は一つだけ採用する。5回目で口が縦に大きい完成窓へ切り替わり、全文を即時表示。「ニュースです」に続けて5つのまとまりを自動で読む。口が開くアニメーションや音声の準備を待たせない。

「きく」は同じニュースを再生。「もういちど」は再生中にも押せ、前の声と演技を止めて選択を消し、候補を再抽選する。遅れた音声処理が次の問いへ戻らない。正誤、時間制限、顔を押す操作は設けない。

### スマホの構図

朱赤の背景に、幅いっぱいの青灰色の顔を置く。選択時の顔は短く、その下に2・1・2の候補穴。完成時は顔の下半分が大きな口となり、本文の全幅を確保する。目は本文の上に載せ、左右にキャラ専用の列を取らない。進行印と「おとな」は顔の外の上端、再生と次ゲームは口の下に置く。文字が第一、口の大きな形が第二、目の表情が第三である。

### 色と読む状態

4色でつくる。朱赤 #EF4B3F が画面の主調、青灰色 #B5C5EB がパコの箱、深紺 #15274A が穴・口と地の文字、白 #F8FAFF が穴内の文字・目・受理の枠。金属の光沢や影は使わず、箱の厚い輪郭だけで玩具らしさを出す。候補22px、完成26pxを起点とする水平な日本語ゴシックで、色より文字の読みやすさを優先する。

口は全文を置く場所なので、準備中も終了後も開けておく。準備中は目を正面にして「こえの じゅんび中」、実際の音声開始で目線を原稿へ向け「パコが よんでいるよ」、終了・停止で「よみおわったよ」にする。発話を示すのは音声開始と終了に応じた静止ポーズと状態文。口パク、音素同期、文字の逐次表示、光るスピーカーは不要である。

再生中は「きく」を「きいているよ」として重複起動を抑える。非対応・失敗時は一度だけ「こえが でなかったよ。ニュースは できたよ」。パコは原稿を見たまま、全文と次ゲームを保ち、可能なら再生を再試行できる。音なしでも状態文とポーズで役割が分かり、動きを減らす設定では切替だけを使う。装飾の欠落や音声イベントの欠落も、本文と操作を止める理由にしない。

### 残す穴と文字

選択の不揃いな5穴、2・1・2、大胆な平面、文字の主役感を残す。完成窓は有機的な穴から、パコの角ばった口へ変える。全364語に絵を足さず、問いマークとパコだけを制作対象にする。短い候補と助詞付き完成形、読み、丁寧な過去形、末尾の「！」を区別して扱う。語の理解が難しい子には保護者の読み添えが残る。

長語では穴を縦に伸ばし、文字を省略しない。タッチ領域は高さ80pxを起点、44 CSS pxを下限とする。長い完成文では口と顔の箱ごと縦に伸び、最初から全文を置く。小画面では目の帯を薄くしても文字を縮めず、縦スクロールで主要操作まで届く。セーフエリア、見えるフォーカス、2・1・2と一致した読み順を確保し、新しい問いと完成へ移動する。初回や設定中にフォーカスを奪わない。

### 対応範囲と自己批判

U・Gは作者とキャスターの関係、5候補と一タップ進行で、Wは語彙と全文、Sは準備・実再生・失敗の明示で対応する。Cの方式・モデル・声JSON、保存時の適用、取消、入力検証は「おとな」に分ける。ゲームを保持し、背景操作を止め、閉じたら入口へ戻す。P・Oのオフライン文字遊び、通信状態、PWA・更新・解析・許諾・公開条件を保ち、Dの確認導線は通常の一巡へ入れない。

大口案を一度批判すると、「口を閉じて発話を示す」演出は本文を隠す。そこで口の開閉を捨て、目線と状態文だけに削った。弱点は、口が画面やテレビに見え、読む人物としての理解が弱い可能性。Vでは読字習熟度×音の有無で「だれが読んだか」と次の操作を確かめる。朱赤の疲れ、中央候補への偏り、誤タップ、再び遊ぶ意欲も観察する。長語、音声失敗、オフライン、小画面、キーボード、対象ブラウザーを確認し、実機とエミュレーションは分ける。実装時にはvalidateと関連E2Eが必要である。

### 静止イメージ指示

スマホ2枚を横並びに描く。主調は鮮やかな朱赤、青灰色の平たい箱、深紺の穴、白い大きな文字の4色。左右とも、二つの大きな目と角ばった大口だけを持つ音読玩具「パコ」を描く。左は上部の短い顔の口に「だれが？」、進行1/5。下の朱赤の面に不揃いな穴を2・1・2で配置し、「ねこ」「いぬ」「うさぎ」「おばけ」「ロボット」を全部表示。右は箱の下半分が縦に大きく開いた口となり、「ねこが／きのう／こうえんで／りんごを／たべました！」をスラッシュなしの5行で全文表示。目線を本文へ向け、「パコが よんでいるよ」を添える。口の下に「きいているよ」「もういちど」。口は大きいが歯や舌は描かず、文字の面積を守る。手足、アンテナ、計器、光沢、発光、波形、余分なボタンは描かない。

実装・画像生成・テスト・実機確認は未実施。大口が読む役に見えるか、強い色で疲れないかは対象児での確認が必要。

## 第1稿 あなから ほうそう

案名は「あなから ほうそう」。キャラクターは、およみロボ「パコ」。遊び心地は「きみの ことばを、まじめに おしらせ」。子どもが原稿をつくり、パコが読む。へんてこな内容にも驚きすぎず、最後まで大切なニュースとして扱う、少し律儀なおもちゃである。楽しさや役割の伝わり方は、対象児の観察で確かめる仮説とする。

### 姿と役割

パコは角の丸い積み木形の小型ロボット。青緑の一つの塊に、二つの黒い目、小さな口、短い手だけを付ける。アンテナ、胸の計器、操作ボタンは持たない。顔を傾け、原稿窓の縁を両手で持つ姿が基本。ニュースを読むときは背筋を伸ばすように顔が起き、口が開く。声のかわいさより、選ばれた言葉を預かって読む態度を人格にする。顔や手は押す場所に見せず、キャラクターへの追加操作も求めない。

### 一巡

開始時は一つの大穴に「ことばを 5つ えらぼう」、その縁にパコと「きみが えらぶ。パコが よむ。」を置く。「はじめる」で選択と音声エラーを消す。選択中、パコは問いの横に座り、穴へ片手を向ける。「だれが→いつ→どこで→なにを→どうした」の各段階で、重複のない無作為の5候補を固定表示。1タップを受理した穴に白い縁と丸印を付け、自動で次へ進む。連打を次の問いへ持ち越さず、演技の終了は待たせない。

5回目で直ちに全文を表示し、パコがその大窓の上縁を持つ。「ニュースです」に続け、5つのまとまりを順に自動読み上げする。「きく」は同じ全文を再生。「もういちど」は途中でも使え、前の音声と演技を止め、選択を消して候補を再抽選する。次の問いにいるパコへ、前の声や遅れた処理が戻らない。正誤、制限時間、ごほうびは加えない。

### スマホの構図

上端に小さな「おとな」と5つの進行印。その下に問いとパコを置き、選択の主面は従来の2・1・2の穴に渡す。完成ではパコと「パコが よみます」を大窓の上縁にまとめ、本文はその下の全幅を使う。キャスター専用の横列や舞台は設けない。文字が第一、読んでいる主体が第二、穴の形が第三の優先順位である。

```text
選択中
┌────────────────────┐
│ おとな      ● ◎ ○ ○ ○ │
│ [パコ→]    だれが？    │
│   ╭────╮  ╭────╮   │
│   │ねこ│  │いぬ│   │
│   ╰────╯  ╰────╯   │
│      ╭────────╮      │
│      │ うさぎ │      │
│      ╰────────╯      │
│ ╭──────╮ ╭────────╮ │
│ │おばけ│ │ロボット│ │
│ ╰──────╯ ╰────────╯ │
└────────────────────┘

読み上げ中
┌────────────────────┐
│ おとな      ● ● ● ● ● │
│   ニュースが できた！  │
│ [パコ◯] よんでいるよ  │
│  手╭────────────╮手  │
│    │ねこが      │    │
│    │きのう      │    │
│    │こうえんで  │    │
│    │りんごを    │    │
│    │たべました！│    │
│    ╰────────────╯    │
│ [きいているよ]        │
│ [もういちど]          │
└────────────────────┘
```

### 色と読む演技

色は5色。バター色 #F5E58A を地、深紺 #202C43 を穴と文字、生成り #FFFDF3 を穴内の文字と受理の縁、青緑 #28786D をパコ、朱色 #C94737 を口と小さな完成印に使う。状態は色に加え、文字、輪郭、丸印で示す。候補22px、完成26pxを起点に、水平な日本語ゴシックを用いる。

パコの口元から原稿窓へ短い一つの突起をつなぐ。両手で窓を持ち、顔が本文へ向くため、単なる飾りより「ここにある文を読む人」に見えると考える。準備中は閉じた口で原稿を見下ろし「こえの じゅんび中」。実際の音声開始で口を開いた姿と「よんでいるよ」に変え、終了・停止で口を閉じて「ニュースが できた」に戻す。口は静止画の切替で成立させ、音素同期、点滅、波形、単語追従を要求しない。標準の日本語読み上げをそのままパコの声として扱う。

再生中の「きく」は「きいているよ」として重複起動を抑える。失敗・非対応時は一度だけ「こえが でなかったよ。ニュースは できたよ」と表示し、パコは閉じた口で窓を持つ。全文と「もういちど」は常に残し、可能なら「きく」から再試行できる。音なしでも姿と状態文で進行が分かる。動きを減らす設定でも同じ静止ポーズを使い、待機を発話に見せない。画像が出なくても名前、状態文、全文、主要操作を残す。

### 穴と文字を守る

大胆な色面、不揃いな穴、2・1・2、完成の大窓を残す。配色を柔らかくし、大窓をパコの持つ原稿へ変えた。専用の絵はパコの姿と問いマークだけで、全364語に挿絵を求めない。助詞付き表記、読み、丁寧な過去形、「！」は語彙の規則どおり扱う。読字が難しい子には問いマークと進行印で補助し、語の意味には保護者の読み添えを想定する。

候補は高さ80pxを起点、44 CSS pxを下限とし、長い語では穴ごと伸ばす。文字を省略せず、完成文も最初から全量を置いて縦にスクロールできる。320px幅や低い横画面ではパコを小さくしても本文を縮めない。5候補と主要操作を隠さず到達可能にし、セーフエリア、見えるフォーカス、2・1・2と一致する読み順を確保する。新しい問いと完成へフォーカスを移すが、初回と設定中は奪わない。

### 対応範囲と自己批判

U・Gは役割分担、5候補、一タップ進行、待たない完成に対応。Wは全語彙と全文、Sは準備・実再生・失敗の区別で対応する。Cの音声方式・モデル・声JSON、保存時のみ適用、取消と入力検証は「おとな」にまとめ、ゲームを保つ。背景操作を止め、閉じると入口へ戻す。P・Oの初回保存後のオフライン文字遊び、PWA・更新・解析・許諾・公開条件を保ち、通信状態は文字で知らせる。Dの音声確認や指定結果の導線は子どもの一巡へ入れない。

初案の大きな胴体とスピーカー穴は、文字より玩具の操作へ注意を誘うと批判した。最終案では顔と短い手に削り、発光や独立した再生装置もなくした。弱点は、窓を持つ姿だけでは読む役と分からない可能性と、中央の穴への注意の偏り。Vでは読字習熟度×音の有無で「だれが読んだか」、迷い、誤タップ、繰り返す意欲を観察する。長語、音声失敗、オフライン、小画面、キーボードを確認し、対象ブラウザーと実機を分ける。実装時のvalidate・関連E2Eも必要である。

### 静止イメージ指示

スマホ2枚を横並びに描く。平らなバター色の背景、深紺の少し不揃いな穴、生成りの大きな水平文字。左は「だれが？」と進行1/5、穴を上2・中央1・下2にし、「ねこ」「いぬ」「うさぎ」「おばけ」「ロボット」を全部表示する。問いの左に青緑の小型ロボ「パコ」。丸角の積み木形、二つの目、小さい口、短い手だけで、片手を候補へ向ける。右も同じパコが大きな原稿窓の上縁を両手で持ち、少し本文へ顔を向けて口を開く。口元と窓を短い突起でつなぎ、「よんでいるよ」を添える。窓には「ねこが／きのう／こうえんで／りんごを／たべました！」をスラッシュなしの5行で全文表示し、下に「きいているよ」「もういちど」。本文が主役。アンテナ、計器、立体陰影、波形、追加ボタンは描かない。
