## 第2稿 リツに おまかせ

案名は「リツに おまかせ」。キャスターは人間の子「リツ」。遊び心地は「わたしが つくる。リツが よむ」。子どもが選んだ内容を、もう一人が引き受けて声にする関係を作る。保護者の読み聞かせと同様に、読む役を任せても、内容を決める主体は子どもに残る。

リツは短い紺色の髪が片側へ跳ね、丸い頬と太い眉を持つ、切り紙風の人間。朱桃色のオーバーオールに白い長袖、手は大きな一枚形。物静かだが、読む番には少し胸を張る。子どもと対等な相手で、選択を促す指差しや採点はしない。選択中は開いた手で待ち、完成後は原稿窓を見る。声の高さや子役音声を人物の成立条件にしない。

開始は群青の面と白い穴が一つ。リツをその上に描き、「ことばを ５つ えらぼう」「はじめる」を置く。開始で古い選択と音声エラーを消す。選択中は上部にリツの顔と胸、隣に問い、その下に５つの横長の穴を縦に並べる。「だれが→いつ→どこで→なにを→どうした」の順を５つの進行印でも示す。各段階の重複しない無作為５候補は位置ごと固定。押した穴に太い白縁と丸印を付けて受理し、１タップで次へ進む。連打・同時押しは最初の一つだけを採用する。

５回目で、穴の並びを一つの白い原稿窓へ替え、全文を即時表示する。見出しは「きみの ニュース」。リツは上部の同じ場所で手を窓の外縁へ添え、視線を本文へ落とす。「ニュースです」に続けて５つのまとまりを自動で読む。「きく」は同じ導入と全文を再生。「もういちど」は古い声と演技を止め、再抽選した「だれが」へ直行する。渡すボタンや演出待ちは設けない。

### スマホの構図

人物と問いの帯は高さ88px程度を起点とし、候補・本文とは別に確保する。リツを窓の脇に置かず、文字はスマホの横幅を使う。

群青 #1646A0は全面背景、紺 #101C3Fは穴・文字・髪、白 #FFFFFFは穴内文字と完成窓。朱桃 #EF4F78は服、薄桃 #F2B79Bは顔と手、青緑 #53D6C4は進行済みの印。６色を平らに使い、状態は形と文言でも示す。問い28px、候補22px、完成26pxを起点に、文字は水平で省略しない。人物の輪郭は明快にするが、文字より強い模様を付けない。

### 読み手としての振る舞い

完成窓は吹き出しにせず、子どもの原稿として独立させる。リツの手がその縁に触れ、視線が本文へ向き、隣に「リツが よんでいるよ」が出ることで声の主を示す。標準の日本語読み上げで成立させる。準備待ちは口を閉じた「こえの じゅんび中」。実際の再生開始でだけ口を開いた姿へ替え、終了・停止で閉じる。音素同期は不要で、動きを減らす設定では静止姿の切替だけにする。再生の重複は防ぐが、次ゲームには進める。

音なしでも「リツは よむひと」と全文・完成表示を残す。失敗時は一度だけ「こえが でなかったよ。ニュースは できたよ」。全文と主要操作を保ち、可能なら「きく」で再試行する。古い音声や遅い完了通知で次ゲームを上書きしない。会話、録音、キャラクター選択、新しい音声機能は加えない。

候補の穴は高さ64px、間隔12pxを起点にし、最低44 CSS pxを守る。長い語は穴を縦に伸ばして折り返す。320px幅、低い横画面、長い全文は縦スクロールで全内容と操作へ到達させる。人物は固定せず、文字を覆わない。新しい問いへ表示位置とフォーカスを移す。問いには小さな種類マークを添え、364語の専用絵は要求しない。語を読めない場合は保護者が５候補を読み添える。

U・Gは開始、固定順の５回選択、即時完成、繰り返しで対応。Wは全364語、助詞付き表記と読み、丁寧な過去形、末尾「！」を保持する。S・Cは標準音声と任意モデル、保護者設定を維持。設定は保存時だけ適用し、取消・閉じるで破棄、ゲームを保持、入力と取得のエラーを分ける。Aは可変高、コントラスト、キーボード、フォーカス、設定中の背景停止と復帰、セーフエリアに対応。P・Oの初回保存後の文字遊び、通信状態、PWA、更新、解析・公開・許諾条件を保ち、Dの確認導線は通常の遊びから分ける。

穴と平面の絵本らしさは残すが、２・１・２を縦５段へ変え、長い語にも同じ横幅を渡す。色は群青を中心に替える。自案の見直しでは、本文の横に立つ人物が原稿幅を狭める弱点を、人物が上・原稿が下の構図に修正した。残る弱点は、人間の読み手が教師に見えることと、読めない子に作者表示が伝わりにくいこと。Vでは読字の習熟度と音の有無を分け、誰が作ったと感じるか、候補の見渡し、誤タップ、補助量、再び遊ぶ反応を観察する。対象ブラウザーと実機、音声の冒頭・失敗・オフラインも分けて確認する。

スマホ２枚を横並びに描く。背景は群青、穴は濃紺、文字は白。平らな切り紙の色面と少し不揃いな輪郭で構成する。キャスターは人間の子「リツ」。片側へ跳ねた短い紺の髪、丸い薄桃の顔、太い眉、朱桃色のオーバーオール、白い袖、大きな手を左右共通で描く。左は上部に開いた手のリツと「だれが？」、進行1/5。その下の横長の穴５段に「ねこ」「いぬ」「うさぎ」「おばけ」「ロボット」を全部表示。右は進行5/5、「きみの ニュース」、本文へ視線を落としたリツを上に置く。手は白い大窓の外縁へ添え、「よんでいるよ」を付ける。窓には「ねこが／きのう／こうえんで／りんごを／たべました！」の全文を改行表示。下に「きく」「もういちど」。人物は文字と重ねず、机、採点印、マイク操作は描かない。

## 初稿 もこに とどける

案名は「もこに とどける」。キャスターはモグラの「もこ」。遊び心地は「じぶんで つくって、だれかに よんでもらう」。子どもがニュースの作り手、もこが受け取って読む相手になる。読み聞かせで大人が声を添えるように、読む負担を引き受けても、言葉を決める役は子どもに残す。

もこは黄土色の丸い頭、横に広い鼻、短い手の平面キャラクター。濃紺の輪郭と小さな目で描く。物静かで、珍しいニュースにも真面目に耳を傾ける。選択を採点せず、読むときは目を本文へ向け、片手を窓の縁へ添える。子どもを見る顔と本文を読む顔を分ける。

開始では一つの穴の脇にもこがいて、「ことばを ５つ えらんで もこに とどけよう」と「はじめる」を出す。開始で古い選択と音声エラーを消す。選択中のもこは上部の小さな専用帯で静かに待つ。「だれが→いつ→どこで→なにを→どうした」を５個の進行印と問いで示し、各段階の重複しない無作為５候補を固定する。押した穴の太い白縁と丸印で受理を示し、１タップで次へ。指が離れる前の連打や同時押しを次段階へ持ち越さない。

最後の選択で、５つの穴は一つの大窓になり、全文を直ちに表示する。見出しは「きみの ニュース」。もこは窓上端の右側へ移り、窓の短いしっぽを口元へ向ける。「ニュースです」に続けて５つのまとまりを自動で読む。「きく」で同じ導入と全文を再生。「もういちど」で古い声と演技を止め、再抽選した「だれが」へ戻る。移動演出を待たず操作でき、時間制限や出来栄えの評価は置かない。

### 声の主と進行

窓のしっぽ、本文を見る目、「もこが よんでいるよ」で声の主を示す。標準の日本語読み上げで成立させ、口の厳密な同期は求めない。準備待ちは口を閉じた「こえの じゅんび中」、実際の開始後だけ口を開いた読む姿、終了・停止では閉じた姿にする。再生中は重複起動を防ぐが、次ゲームへ進める。動きを減らす設定では静止ポーズの切替だけにする。

音なしは「もこは よむひと」と窓の関係を保ち、全文と完成・操作の表示で進める。失敗時は一度だけ「こえが でなかったよ。ニュースは できたよ」。全文と「もういちど」を保ち、可能なら「きく」で再試行する。停止・失敗で古い演技を残さず、遅れて来た音声処理も次ゲームへ反映しない。新しい音声、録音、会話、着せ替えは加えない。

長い候補では穴を縦に伸ばし、全文も語のまとまりで折り返す。省略や文字数上限は設けない。候補は高さ80px、間隔12pxを起点とし、最低44 CSS pxを守る。320px幅や低い横画面は縦スクロールを許し、窓・人物を固定して文字を覆わない。新しい問いへ表示位置とフォーカスを戻す。読みに不慣れな子には問いの小さな種類マークを添えるが、364語の絵を前提にせず、必要なら保護者が５候補を読み添える。

ベースの穴、平面、文字の主役感を残し、黄色を少し落ち着かせ、穴を「相手へ届ける窓」として使う。初案の弱点は、大窓がもこの吹き出しになると作者までもこに見えることだった。修正して「きみの ニュース」を独立した見出しにし、もこは窓の外の読む役に限定した。それでも読めない子には作者表示が伝わりにくい。Vでは読字の習熟度と音の有無を分け、「だれが作ったか」、中央候補への偏り、長語での誤タップ、保護者の補助量と再び遊ぶ意欲を観察する。対象ブラウザーと実機、音声の冒頭・失敗・オフラインも別に確認する。
