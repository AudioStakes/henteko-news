# となりの ニュースまど

キャスターは、かめの「トト」。遊び心地は「わたしがえらぶ、トトがつたえる」。子どもが五つの言葉を選び、トトが全文を読む。音なしでも役割を示す仕組みは、顔と吹き出しの接続です。効果は未検証の仮説です。

## 姿と関係

丸い白い顔、点の目、小さな口、緑の甲羅。輪郭と目を濃く描き、小さくても表情を潰さない。落ち着いた好奇心を持ち、おかしなニュースも真面目に読みます。選択を評価しません。口元につながる吹き出しが、選択中は問い、完成後は全文を囲みます。顔は操作対象にしません。

## 一巡とスマホの構図

開始はトトと「ことばを 5つ えらぶと、トトが ニュースを よむよ」、大きな「はじめる」。選択と音声エラーを消して始めます。選択中は上端に進行五枠、その下に顔と「だれが？」の吹き出し。候補は外へ、同じ窓を縦に五つ並べ、読む順と押す順を揃えます。

押した窓に太枠と丸印が付き、進行枠が埋まって次へ。「いつ→どこで→なにを→どうした」まで自動進行し、段階内の五候補と位置は固定。指が離れるまで次を受け付けず、連打を持ち越しません。最後の選択直後、吹き出しを画面幅へ広げ、全文を一度に表示。トトは同じ左上から、目と片手を本文に向けます。

```text
選択中
おとな　■□□□□
(トト)─〈だれが？〉
[ねこ　　　　　]
[いぬ　　　　　]
[うさぎ　　　　]
[おばけ　　　　]
[ロボット　　　]

読んでいる時
おとな　■■■■■
(トト) ▶よんでいるよ
  ╲──────────┐
  │ねこが            │
  │きのう            │
  │こうえんで        │
  │りんごを          │
  │たべました！      │
  └──────────┘
[きく] [もういちど]
```

「ニュースです」に続けて五つを区切って自動読み上げ。「きく」は同じ導入と全文を再生し、重複開始を抑えます。「もういちど」は声と演技を止め、選択を消して再抽選。遅れた音声完了で次ゲームを上書きしません。

## 顔と文字の優先順位

顔は64〜72px程度で固定。問い28px、候補22px、全文26pxを起点に、水平なゴシック体で示します。全文は顔の下へ画面幅を使う。背景は砂色 #F5F0E3、文字・候補窓・輪郭は濃青緑 #203D48、本文窓と候補文字は白 #FFFFFF。甲羅は #6C8975、完成の丸印は #C87543 の五色。状態には文字と形も添えます。

## 声の状態を見せる

準備中は口を閉じ、手を下ろし「砂時計＋こえを じゅんび」。実際の再生開始でだけ、口を小さく開き、本文を指す静止ポーズと「▶ よんでいるよ」へ。口パク、語の追跡、点滅は不要。終了・停止後は閉じた口と「■ よみおわり／とまったよ」。音声イベントが欠けても待ち続けず、操作可能へ戻します。

失敗は一度だけ「こえが でなかったよ。ニュースは できたよ」。非対応時も全文と操作を保ち、可能なら「きく」で再試行。無音でも、進行五枠と口元から全文への接続で役割と完成を示します。OSの動きを減らす設定では拡大・移動をせず、同じ位置で枠・印・静止ポーズを切り替えます。

## 残すもの、変えるもの

平らな色面、不揃いな窓、文字の主役感を残し、2・1・2は縦五段へ。顔の場所と長語の幅を確保し、全面色を和らげます。長語は窓を縦に伸ばし、省略・縮小しない。高さ64px、間隔12pxを起点に、下限44 CSS pxを守る。320px幅や低い横画面は縦スクロールを許し、顔の固定表示で本文を覆いません。長文も語のまとまりで折り返し、末尾の操作まで到達できます。

## 要件への対応と確認

U・Gは五段階各五候補、一タップ進行、無評価の繰り返し。Wの全364語、助詞付き全文、読み、丁寧な過去形、末尾「！」を維持します。語の絵は不要で、未読語には保護者の読み添えが残る。S・Cは標準音声で成立させ、任意モデルと共有設定を保持。「おとな」で編集し、保存時適用、取消時破棄、入力検証・復元・取得失敗の区別を維持します。

Aは安全領域、キーボード、可視フォーカス、問い・完成への移動。設定中は背景を止め、閉じると入口へ戻す。P・Oの保存後オフライン、通信復帰、PWA・更新・配信、計測範囲、通信説明、許諾、メタ情報を維持。画像が欠けても文字と操作は残します。Dの音声・指定結果確認は遊びから分離。追加の音声制作や会話機能は不要です。

自己批判では、うなずきと進行枠の跳ねが重なると、文字より顔を待つ遊びになると考え、その演出を削り通常時も静止中心に修正しました。弱点は下の候補の見落としと、吹き出しが通じない可能性。Vでは読みの習熟度×音の有無で、五候補への到達、顔から全文への視線、再生・次ゲームの理解を観察。対象ブラウザー、実機、長語、音声失敗、オフライン、動きを減らす設定も確認します。

## 静止イメージの指示

スマホ二枚を横並びに描く。砂色の背景に、白い丸顔、点の目、小さな口、くすんだ緑の甲羅を持つ同じかめ「トト」を両画面の左上へ小さく配置する。輪郭と文字は濃い青緑。左は上に進行五枠、トトの口元につながる白い吹き出しに「だれが？」。その下へ濃青緑の横長い窓を五段並べ、「ねこ」「いぬ」「うさぎ」「おばけ」「ロボット」を白い水平文字で全部見せる。右はトトが小さく口を開け、片手で本文を指す静止姿勢。「▶ よんでいるよ」の下に、口元と尾で接続した大きな白い吹き出しを置く。「ねこが／きのう／こうえんで／りんごを／たべました！」をスラッシュなしの五行で大きく表示。下に「きく」「もういちど」。文字は顔より大きく目立たせ、影、紙吹雪、発光、踊る文字は加えない。

実装・画像生成・テスト・対象児の確認は未実施。音なしでの役割理解と長語時の見通しは、試作後の確認が必要です。
