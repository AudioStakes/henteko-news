# キャスターがニュースを読むUIの提案条件

## 今回の依頼

ユーザーは前回の絵本アートディレクターによる「ことばの あな」を最も気に入った。
この案を出発点に、新しいキャラクターをニュースキャスターとして登場させ、そのキャラクターが完成ニュースを読んでいると感じられるUIを考える。
配色は自由であり、良い理由があればベースの構図自体を調整してよい。
今回は複数の案をユーザーが比べて選ぶための提案のみとし、実装しない。

## 設計の入力

1. この資料に書かれた今回の依頼。
2. [選ばれたベース案の本文](selected-base.md)。採用された第2稿だけを抜粋している。
3. [選ばれたベース案の静止イメージ](../ui-proposals/images/c.png)。既存アプリの画面ではなく、前回の新規提案画像である。
4. [全75項目の要件専用資料](../ui-proposals/requirements-only-brief.md)。今回変更された箇所は今回の依頼を優先する。

以上以外のアプリのコード、画像、資料、過去の会話、他の提案は参照しない。
他の提案者と案を共有しない。
現在のアプリがどうなっているかを推測しない。

## ベースの特徴

平らで大胆な色面と、少し不揃いな穴が特徴である。
選択では5つの穴を上2、中央1、下2に配置し、完成では一つの大きな窓に文章を見せる。
初期案のレモン色と濃紫は変更してよい。
穴の発想、絵本のような簡潔さ、文字の主役感のどこを残し、どこを変えたかを説明する。
キャラクターを足すためだけに、文字が小さくなる、候補が隠れる、完成文を順に出して待たせる構成にしない。

## キャラクターで考えること

- 名前、姿、性格、ニュースを読む時の態度を決める。
- 5歳の子どもとの関係を一言で説明する。子どもが何をし、キャラクターが何をするかを明確にする。
- 開始、選択中、完成、読み上げ中、再生、次ゲームでのキャラクターの位置と役割を考える。
- 画面にマスコットを置くだけでなく、声の主がそのキャラクターだと視覚でも分かるようにする。
- 新しい音声合成、声優音声、会話AI、録音、マイク入力、キャラクター選択、着せ替え、収集を必須にしない。キャスターは1案につき1人で成立させる。
- 声の性格は表現方針として提案できるが、まずは標準の読み上げでも成立する設計とする。
- 口の動きは音素や単語に厳密に同期させることを前提にしない。実際の音声開始と終了に応じる簡単な演技や静止ポーズでも、読む役だと伝わるようにする。
- 音声の準備待ちと実際の再生を区別し、待機中にしゃべっている演技を続けない。
- OSの動きを減らす設定では静止したポーズで、音なしでもキャスターの役割と進行が分かるようにする。
- 音声失敗時も全文と主要操作を保ち、キャラクターが失敗を責めたり進行を妨げたりしない。

## 保持する遊び

「だれが → いつ → どこで → なにを → どうした」の順で、各5候補から1つずつタップする。
1回のタップで自動進行し、最後の選択で完成全文をすぐ見せ、キャスターが自動で読み始める。
再生ともう一度を維持し、読み上げ中に次ゲームへ進めば前の声と演技を止める。
全364語、長い語、助詞、読み、丁寧な過去形を保持する。
ニュースの全文は読み上げ中も最初から確認でき、必要なら縦にスクロールできる。
音声の失敗と、初回保存後のオフラインでも文字で遊べる条件は変えない。
保護者向け音声設定と開発用の確認導線は、子どもの通常の遊びから分ける。

## 共通の表示例

選択状態の仮候補は「ねこ」「いぬ」「うさぎ」「おばけ」「ロボット」の5つとする。
完成文は「ねこが／きのう／こうえんで／りんごを／たべました！」とする。
これらは比較用の例であり、語彙データの変更を意味しない。

## 提案の報告項目

- 案名、キャラクター名、遊び心地をそれぞれ短く。
- キャラクターの姿と性格、および子どもとの関係。
- 開始から5回の選択、完成、自動読み上げ、再生、次ゲームの一巡。
- 選択中と読み上げ中の、スマホ上の構図と短いワイヤー。
- 配色4〜6色と役割。文字とキャラクターの優先順位。
- キャスターが読んでいると伝える仕掛け。音声待機、再生中、停止、失敗、音なし、動きを減らす場合の表現。
- ベースから残した点、変えた点と理由。
- 長い候補と長い完成文、小画面、誤タップへの配慮。
- 要件のグループへの対応と、この案の弱点、試作後に確認すること。
- 静止イメージを作るための指示を300〜450字。スマホ2枚を横並びにし、左は5候補の選択、右はキャスターが完成全文を読む状態。左右で同じキャラクターを描く。

効果は未検証の仮説として書く。
それぞれの人格や見た目の案を、他の案より優れていると順位付けしない。
