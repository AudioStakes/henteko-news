# キャスターを加えるための共通アイデア

以下は、複数の案から組み合わせても使える表現上のアイデアである。
採用を決めた仕様ではなく、楽しさへの効果はまだ検証していない。

## 子どもが作り、キャスターが読む

子どもはニュースの内容を決める人、キャラクターはその内容を届ける人とする。
キャスターの導入を「きみの ニュースを おつたえします」のようにすると、自分の選択と読み上げの関係を短く示せる。
選ぶたびの採点や長い褒め言葉は挟まず、できた文章そのものを楽しむ。

## 穴を放送の窓として使う

ベース案の穴を、キャスターが登場する小窓や、原稿を映す窓として捉え直せる。
選択時の5つの穴と、完成時の大きな一つの窓を、同じ形の言葉としてつなぐ。
キャラクターを独立した大きな領域へ足す方法のほか、窓の縁から顔や手を見せる方法もある。
文字の面積を保ちながら、「この子が読んでいる」というつながりを作る。

## まじめな読み手と、おかしな内容を組み合わせる

キャスター自身が毎回ギャグを言わなくても、子どもが作った不思議な文をまじめに読む姿で面白さを狙える。
大きな驚きや突っ込みで本文を遮らず、少し首をかしげる、原稿へ視線を戻す程度の表現でもよい。
読み上げる文章に勝手な言葉を足さない。

## 声の主を形でも伝える

原稿の窓をキャラクターの方へ少しつなぐ、手元に原稿を持たせる、読む姿勢と待つ姿勢を変える方法がある。
マイクを持たせる場合は舞台の小道具として描き、録音するための操作ボタンと取り違えにくくする。
キャラクターの顔も6つ目の選択肢に見えないよう、候補の領域と役割を分ける。

## 口パクより、読む姿勢を先に決める

音素に合わせた口の動きや単語ごとの強調がなくても、顔の向き、原稿を持つ手、音声状態の印で読み手を表せる。
音声が準備中の間は待つ姿、実際の再生中は読む姿にする。
次のゲームへ進む、音声が止まる、設定を変える場合は、前の声と演技を一緒に終える。
動きを減らす設定では、静止した2つの姿勢でも区別できる表現を選ぶ。

## 全文を先に見せ、音がなくても同じニュースを届ける

最後の選択が終わった時点で、キャスターと完成文を同時に見せる。
文章は読み上げに合わせて1行ずつ出すのではなく、全文を確認できるようにする。
音声に失敗したらキャスターが本文を示す姿にし、文章と「きく」「もういちど」を残す。
標準音声の端末差もあるため、特定の声質がなければ成り立たない性格や演出を必須にしない。
