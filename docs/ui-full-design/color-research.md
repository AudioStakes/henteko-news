# 5歳前後の子どもの色の好みと配色の判断

このメモは、水色版を検討した際の調査と指定色の記録である。
現在採用されているAのオレンジ配色は[全画面デザイン案](README.md)を参照。

調査日：2026年10月21日。
黄色を主役にした画面で濃紫を明るい色へ置き換えるため、幼児を含む原著研究を確認した。
研究は候補色を考える材料に使い、特定の色が日本の5歳児の操作や学習を改善するという根拠にはしない。

## 明るさと彩度を変えた積木の研究

Chenら（2023）は、中国の幼稚園から4〜7歳の23人を募集し、有効データのある18人について、6種類の色調の積木で自由に遊ぶ際の視線を測定した。
論文の「108」は参加者数ではなく、18人が6条件で遊んだデータセット数である。
白を加えて明るさを上げ、同時に彩度を下げると、積木を注視する時間の割合は途中の条件まで増えたが、さらに白に近づけると低下した。
これは「明るいほどよい」「彩度が高いほどよい」という単調な関係を支持しない。
ただし、小規模な積木の実験であり、明るさと彩度を独立に操作していないため、どちらの効果かは分離できない。
注視時間は好みの間接指標であり、画面上の文字の読みやすさや誤操作を測った結果ではない。
出典：[Using head-mounted eye trackers to explore children’s color preferences and perceptions of toys with different color gradients](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1205213/full)。

## 5〜6歳の色相、彩度、明るさの選択

Mousavi SamimiとSadraei Tabatabaei（2022）は、イランのタブリーズの4幼稚園に通う5〜6歳109人に、モニター上の16配色と屋内、屋外の遊び場画像を見せ、壁に使いたい配色を選んでもらった。
屋内では寒色系とHSVの彩度75、明度75、屋外では暖色系と彩度75、明度50が最も選ばれた。
居住地区の社会経済的な群によって明度の好みが異なり、この標本では性別や5歳と6歳の差は有意ではなかった。
同じ年齢層でも、場所や生活背景によって好みが変わる点が今回の判断に関係する。
ただし、遊び場の壁を想定した選択であり、スマートフォンのボタンや日本の子どもに同じ値が最適とは言えない。
HSVの明度は、文字の可読性に使う相対輝度やコントラスト比と区別する。
出典：[Preschool children's indoor and outdoor playground HSV color preferences](https://doi.org/10.1002/col.22759)、[著者公開の原著本文](https://www.researchgate.net/publication/356616775_Preschool_children%27s_indoor_and_outdoor_playground_HSV_color_preferences)。

## 文化と色の好み

Davisら（2021）は、ペルー、バヌアツ、コンゴ共和国の小規模社会とオーストラリアの都市で、4〜11歳の計232人に、印刷した色面や玩具の線画の5組から好きな方を選んでもらった。
ピンクの選択に関する男女差は都市の標本で見られたが、3つの小規模社会の標本では有意ではなかった。
この結果は、色の好みに文化や経験が関わることを支持し、性別から好みを決めつける配色の根拠にはならない。
ただし、主にピンクと青の比較であり、5歳だけの結果や、黄色、水色、緑の配色順位を示す研究ではない。
出典：[Cultural Components of Sex Differences in Color Preference](https://pmc.ncbi.nlm.nih.gov/articles/PMC8451877/)。

## 今回の画面への反映

今回の画面では、明るい水色を大きな面、青緑を文字と輪郭、明るい緑を次へ進むボタンに使う。
これは、明るさと彩度を調整した候補を試すという設計上の判断であり、「5歳児はこの色が最も好き」という研究結果ではない。
確認した研究から、濃紫という色相自体が子どもに不向きとも、水色が緑より優れるとも結論づけない。
全画面を白に近い淡色に寄せず、文字や操作の境界を区別できる配色とし、色だけで状態を伝えない。
個々の子どもの好みと、言葉を読めるか、押す場所が分かるか、誤って押さないかは別々に確かめる。
今回確認した原著には、日本の5歳児がスマートフォンの言葉遊びを使う際の操作成績や学習効果を、この配色で比較した結果はない。

## 採用する配色

大きな面の濃紫を水色へ替え、濃い色は文字と細い輪郭に限定する。
黄色、ロゴ、ひよこ、画面構成は維持し、選択肢ごとに別の色を割り当てない。

| 役割                                   | 指定色    |
| -------------------------------------- | --------- |
| 画面の黄色                             | `#FFF06A` |
| 候補と完成文の水色                     | `#8DDEF0` |
| 文字の青緑                             | `#164B5A` |
| 操作領域の細い輪郭                     | `#286C80` |
| 「はじめる」「きく」のコーラル         | `#FF9C83` |
| 「つぎをつくる」「設定を保存」のミント | `#AFE6BE` |
| 設定と通知のクリーム                   | `#FFF9E9` |
| 無効な操作の淡い灰緑                   | `#DCE8E5` |
| 設定エラーの文字                       | `#9C3B2E` |

水色は既存ロゴにも含まれる色相を拾い、黄色い背景とひよこを引き立てるために選んだ。
コーラルとミントは操作の役割を分けるアクセントとし、5候補は同じ水色でそろえる。
これらのHEX値や配色の調和は、研究で順位付けされた値ではなく、このUIのための設計判断である。

## 明るくする場合の読みやすさ

通常の文字は4.5:1以上、大きな文字は3:1以上のコントラストがWCAG 2.2の基準となる。
今回は大きな文字でも4.5:1以上を目標とし、白文字を濃い青緑の文字へ替える。
出典：[W3C Understanding Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

次の値は、指定した単色のsRGB値を相対輝度に変換し、`(明るい方の輝度 + 0.05) / (暗い方の輝度 + 0.05)` で計算した。
数値は表示のために小数点以下2桁へ丸めており、合否の判断には丸める前の値を使う。

| 前景と背景            | 比     |
| --------------------- | ------ |
| 青緑の文字 / 黄色     | 8.19:1 |
| 青緑の文字 / 水色     | 6.32:1 |
| 青緑の文字 / コーラル | 4.72:1 |
| 青緑の文字 / ミント   | 6.80:1 |
| 青緑の文字 / クリーム | 9.13:1 |
| 輪郭 / 水色           | 3.90:1 |
| 輪郭 / 黄色           | 5.05:1 |

水色と黄色の塗り同士の比は約1.30:1なので、候補の押せる範囲には約2 CSS pxの青緑の輪郭を付ける。
W3Cは必要な操作や状態を識別する視覚情報に隣接色との3:1以上の差を求める一方、文字などで識別できる全ボタンに枠を必須とはしていない。
ここでは5歳児が押せる範囲を見つけやすくするため、明瞭な輪郭を設ける設計を選んだ。
出典：[W3C Understanding Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

選択済みはチェック、読み上げ中は文言と姿、無効な再生は状態文言とアイコンでも伝え、色だけに依存しない。
比の計算は指定色の検証であり、生成PNGの全画素や実装済みUIが基準に適合したことを示すものではない。
画像生成では指定色に揺れが生じるため、実装時はこの指定色を設定して実機で再確認する。
アプリの実装と、日本の5歳児による好みや操作性の比較確認は行っていない。
