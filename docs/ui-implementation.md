# オレンジ版UIのアプリへの反映

[採用したHTML](ui-prototype/index.html)と[全画面デザイン](ui-full-design/README.md)をReactの実画面へ反映しています。
開発サーバーのルートURL `/` から、既存の全語彙を使う5段階のニュース作り、実音声、設定の保存を操作できます。
HTML内のモック、表示確認ツール、模擬の364語カウンターは本番へ入れていません。

## 構成

`AppView` は既存の[application API](application-api.md)の状態・操作に接続します。
開始、候補のIDによる選択、完成文の生成、敬体変換、設定の検証・永続化、音声確認のキューは既存処理を使います。
開始・選択・結果では、固定したひよこキャスター、5つの進行ドット、通常2/1/2の穴、長語の1列表示を使います。
結果の本文は省略せず、必要な縦スクロールで操作へ到達する構成です。
最長の文と本文領域の幅に合わせて5文共通の文字サイズを選び、通常は1文1行に収めます。
標準文字設定で18pxを下限とし、極端な長文や文字拡大では折り返して全文を表示します。
旧構図に専用だった文字とキャラクターの寸法計算、および使わなくなったランダム画像一覧は削除しました。

設定は保存時だけ適用し、取消・閉じる・Escapeでは編集中の値を破棄します。
開発者用 `/words-audio-check` は直接URLとして保ち、実際の全語彙を最初・続き・カテゴリ別に再生できます。
選択や結果の途中で設定を開閉してもゲームの選択は保持します。

## 音声の状態

公開状態に `speech.phase` を追加しています。
`idle`、`preparing`、`speaking` を、受付・合成、実際の再生イベント、終了・失敗・取消に合わせて切り替えます。
準備中は口を閉じた姿、実再生中は原稿を読む姿を表示します。
従来の `isSpeaking` は準備を含むbusy状態として互換性を保ち、処理中は「きく」を無効にして「つぎをつくる」を有効にします。
最後の候補はクリックの中で同期的に処理し、ブラウザー音声の開始を不要なタイマーへ遅延させません。

## 素材と配色

背景は `#FFEA66`、候補と本文は `#FFC88F`、文字は `#5A2D16`、輪郭は `#954315` です。
有効な主操作は `#FFA35C`、次のニュースと取消は `#FFF4D8` です。
ロゴとトップのひよこは既存素材、待機・原稿姿は[プロトタイプで生成した素材](ui-prototype/asset-prompts.md)を使います。
フォントとキャスターを `public/assets/` に含め、通常のPWAビルドのキャッシュ対象にしています。
[フォントのライセンス](../public/assets/rounded-black.LICENSE.txt)も同梱しています。

## 検証

次の検証を実行し、すべて成功しました。

- `npm run validate`：lint・整形・型・語彙検証、27ファイル246件のユニットテスト、Nodeスクリプトのテスト、本番ビルド。
- `npm run test:e2e -- --reporter=line`：UI導入時にChromium・Firefox・WebKit・Android・iPhone・iPadの設定で150件。
- `npm run test:e2e -- tests/usability.spec.ts --reporter=line`：文字サイズの調整後に同じ6設定で48件。指摘文の1行表示と、同一ページの320→390→696→320pxへの幅変更を含みます。
- `RUN_SPEECH_SMOKE=1 npm run test:e2e -- tests/speech.spec.ts --project=chromium --reporter=line`：実際のSupertonicモデルが無音でない44,100HzのPCM WAVを合成し、ブラウザーのネイティブ再生が開始すること。

ブラウザーテストの対象は、通常ゲーム、設定の保存・取消、長語・長文、キーボード操作、オフライン、直接URL、音声の準備・再生・取消です。
小さい画面で候補の全文と操作を保つ回帰検証を追加し、3種類のブラウザー・3画面サイズでも全5カテゴリのラベル寸法を測定しています。
実装とテストを分担し、独立レビューとブラウザー検証で見つかった配置・文字寸法の問題を修正しました。

実機のiPhone・Android、および5歳児による操作評価は別途必要です。
