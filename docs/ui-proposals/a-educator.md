# ことばの こばこしんぶん

## ひとことでどんな遊び心地か

五つの小箱に、自分で選んだ言葉を一つずつしまう遊び。全部そろうと箱の下から新聞が広がり、「これを選んだから、こうなった」が目でたどれます。小箱は進行の印で、ドラッグする道具にはしません。

## 選択から完成までの一巡

開始状態では、空の小箱五つと「ことばを 5こ えらんで、ニュースを つくろう」、大きな「はじめる」を表示します。押すと「だれが」の問いと、縦に並んだ五候補が現れます。候補は同じ大きさの札で、選ばれやすさに差をつけません。

例えば「ねこ」を一度タップすると、その札に太い囲みとチェックが付き、一番目の箱が埋まります。追加の確定操作なしで「いつ」へ進みます。受け付けた直後は候補操作を止め、指を離してから次の問いを操作できるようにし、連打で段階を飛ばしません。演出は短く、動きがなくても箱の変化と問いの更新で分かります。

順序は「だれが→いつ→どこで→なにを→どうした」。候補は各段階で重複のない五つを無作為に出し、その段階にいる間は固定します。設定を開いても変えません。

最後の選択で五箱がそろい、すぐに全文を表示。「できたニュースを おつたえします」に続いて、選んだ五つのまとまりを順に自動再生します。「きく」は同じニュースを再生し、再生中は二重に開始しません。「もういちど」は音声と前の選択を消し、再抽選した「だれが」から始めます。

## 短いワイヤー

選択の残り四語は配置説明用の仮ラベルです。語彙原本の追加は意味しません。

```text
| こばこしんぶん  [設定]|

```

## 見た目

背景は温かい紙色 `#FFF7E8`、札と新聞は `#FFFFFF`、文字は `#253333`。現在の箱と選択枠に深緑 `#24665C`、埋まった箱に薄い朱色 `#E8A58B`、未選択の箱に灰色 `#E6E0D6`を使います。色だけで状態を表さず、数字、チェック、枠線を併用します。

文字は端末標準のゴシックを中心に、問い26px、候補24px、完成文22pxを出発点とします。設定は別の密度で16px程度。最終寸法は実機で確かめます。候補は高さ60px以上、十分な間隔を設け、長い語では札自体を伸ばします。完成文は語のまとまりを保ちながら折り返し、省略しません。低い画面では自然に縦へスクロールします。

## 音なしと、読みの難しい子への配慮

各段階には「人の顔／時計／場所／物／動き」の五つの補助絵を用意し、問い、現在の箱、候補札の端で同じ印を繰り返します。補助絵は何を選ぶ段階かを知らせる役割です。候補の意味まで同じ絵で説明できるとは扱いません。

全364語の専用絵が完成済みという前提は置かず、まず五つの段階絵と短い候補表記で構成します。読みが難しい語は保護者の読み助けを想定します。音なしでも開始、選択の受理、進行、完成は視覚で追えますが、読めない子が候補の意味まで自力で理解できるかは、この案の重要な未確認点です。

## 設定とエラーの扱い

「設定」は上端の控えめな入口に置き、音声方式、モデルフォルダー、声JSONを保護者向けの別枠で扱います。背景の遊びは操作できなくし、閉じると入口に戻します。保存だけが変更を適用し、取消、保存せず閉じる、Escapeでは編集を捨てます。ゲームの進行と完成文は保持します。

入力エラーは該当欄の直下に理由を示し、書式の問題と取得失敗を区別します。保存できなくても、その場の遊びは続けられます。音声の待機、再生中、利用不可も文字と印で表示し、失敗時は「こえが でなくても あそべるよ」を一か所に出します。標準音声から別方式へ勝手に切り替えません。

## 要件グループ対応

- **U・G**：自分で開始し、五候補を一回ずつ選び、五段階を完走。正誤、制限時間、追加操作を設けません。
- **W**：全364語と候補・完成文・読みの区別を保持。助詞、動作の丁寧な過去形、文末「！」を含め、長文も全文表示します。
- **S・C**：完成時の自動音声、再生、重複防止、古い音声の停止、設定の保存・取消・検証を状態として示します。
- **A**：320px幅から横画面、PCまで操作を切らず、キーボード、明瞭なフォーカス、問いへの移動、セーフエリア、動きの抑制に対応します。
- **P・O**：文字のオフライン遊び、通信状態、PWAと更新方式を維持。箱の新アイコンを各サイズに展開し、言葉や完成文を解析へ送りません。プライバシーと許諾表示は設定側から確認できます。
- **D・V**：開発用音声確認と指定結果の確認は遊びの外に保持。読みの習熟度、音の有無、実機とエミュレーションを分けて観察します。

## 弱点と後で確かめること

箱が埋まる表現を、言葉が保存された合図として受け取れるかは観察が必要です。五候補の縦並びで下の候補を見落とさないか、長文時にも「もういちど」へ届くか、親の読み助けがどれほど必要かを確かめます。楽しさや再び遊ぶ意欲は、対象児の反応から判断します。
