# ことばの ぱちんプレス

ひとことで遊び心地：**大きな部品を指でぱちんとはめるたびに、自分だけのニュースができていく。**

幼児向けのはめ込み玩具を手掛かりにした、小さな言葉の工作台。画面の中央に並ぶ5枚の候補は、白い樹脂でできた厚い押し部品として描く。選ぶと部品が少し沈み、ふちの影が縮んで、上の台座に言葉の小片が収まる。指に本当の抵抗は返せないため、短い変形と位置の変化で「押せた」を伝える。ドラッグや精密な位置合わせは要求しない。

## 開始から繰り返しまで

開始時は、空の穴が5つある台座と、大きな「つくる」部品を見せる。「ことばを 5こ えらぼう」の一文を添え、自分で押して始める。

①「だれが」で「ねこ」を1タップ。部品が約120ミリ秒沈み、台座の1つ目に「ねこが」が入る。②「いつ」で「きのう」、③「どこで」で「こうえん」、④「なにを」で「りんご」、⑤「どうした」で「たべる」を選ぶ。各段階とも、重複しない5候補から1つを選ぶだけで次へ進む。候補はその段階中には入れ替わらない。

アクション選択例の「たべる」は共通例用の仮語であり、語彙を変更する提案ではない。

台座は「1/5」の数字、埋まった穴、現在位置の太い輪郭を併用する。次の問いを表示する位置は揃え、前の押下を次の選択へ持ち越さない。最初の1候補だけを採用し、指を離してから次の入力を受け付ける。

最後は台座の下から、厚紙のニュース札が短く現れる。「ねこが、きのう、こうえんで、りんごを、たべました！」の全文を表示し、「ニュースが できました」に続いて自動読み上げする。紙が出る演出を待たず「きく」「もういちど」を使える。「もういちど」で音声と選択を消し、空の台座と新しい5候補から始める。共通例の表記は説明用であり、語彙原本の変更を意味しない。

## 見た目と材質

色は5色。背景のクリーム `#FFF4DE`、文字・輪郭の深緑 `#243A32`、候補部品の白 `#FFFFFF`、選択済み部分の淡い青緑 `#A9CEC1`、現在位置と完成札の留め具の黄 `#F2C65C`。色だけで状態を分けず、穴・はまった部品・太い輪郭を描き分ける。

文字は端末標準の日本語ゴシックを使い、候補は22pxを出発点とする。部品は高さ56px以上、間隔8pxを仮寸法とし、長い語では高さを伸ばす。省略記号で切らない。装飾は浅い影と丸いふちに絞り、木目など文字を邪魔する模様は使わない。設定や再生の印も、同じ丸い部品と深緑の線で統一する。

## 音なし・読みの難しい子への配慮

問いには種類を示す簡単な印を添える。人物、時計、場所、もの、動きの5種類だけ制作し、364語それぞれの専用画像は前提にしない。質問、押した反応、進行、完成は視覚だけでも追える。操作音は短い「こつ」で、なくても成立させる。動きを減らす設定では沈み込みを省き、輪郭と台座の更新で示す。

種類の印は語そのものの意味までは説明できない。候補が読めない場合は保護者が読む共同遊びを想定し、自立操作できる範囲を試作で確認する。

## 設定と失敗時

「おとなの設定」は遊びの部品より控えめな入口から開く。音声方式とモデル関連の入力を置き、保存でのみ適用する。取消・保存せず閉じる・Escapeでは編集を破棄し、遊びの進行と完成文を保つ。初期値へ戻す操作も保存までは未反映。入力エラーは対象欄に理由を示し、書式の誤りと取得失敗を区別する。

音声処理中は「こえの じゅんび」、再生中は「よんでいるよ」を表示し、重複再生を防ぐ。失敗時は「こえは おやすみ。ニュースは できているよ」と一度表示する。完成札と繰り返し操作は残し、再試行できる場合は「きく」を戻す。

## 要件グループへの対応

U・Gは押す→はまる→次の問いという一貫した反応で構成する。Wは短い候補表記と助詞付き完成表記、読み、丁寧な過去形を分け、全364語を維持する。長文は札を縦に伸ばす。S・Cは標準音声と任意モデルを明示的に選び、設定保存や再開始で古い音声を止める。

Aは縦スクロール、セーフエリア、見えるフォーカス、設定内のフォーカス管理で支える。PCでも同じ順序で操作する。P・Oは軽い形状表現でオフラインの文字遊びとPWAを保ち、解析・公開・許諾の条件を引き継ぐ。Dの確認機能は子どもの導線に含めない。Vでは指定画面寸法、実機、音なし、音声失敗、オフラインを分けて確認する。

## 弱点と試作後に確認すること

弱点は、押す感触の表現が端末によって平板になることと、非読字の子には候補の意味を伝えきれないこと。試作では押下認識、連打、5候補の見つけやすさ、完成への反応、もう一度遊ぶ意欲を観察する。楽しさへの効果は未確認で、今回は実装・テストを行っていない。

## 静止UIモックアップ用指示（付記）

390×844相当のスマホ画面を2枚、横並びに描く。左は「だれが？」の選択中で、ねこ・いぬ・おばけ・ロボット・うさぎの5候補すべてを、省略せず同じ大きさの白い押し部品に表示。上部に5穴の台座と1/5。右は完成札に「ねこが、きのう、こうえんで、りんごを、たべました！」の全文を順に配置し、「きく」「もういちど」を大きく表示。クリーム背景、深緑の文字、浅い影、青緑の選択済み部品、黄色い留め具で、柔らかな樹脂玩具と厚紙の質感を表す。文字の読みやすさを優先し、キャラクターや追加機能は描かない。
