## 第2稿

### 案名と遊び心地

### 「ことばの あな」

「どの穴をのぞいても、へんてこな一文につながる。」

大胆な選択は、画面をレモン色で満たし、5候補を濃紫の「穴」として2・1・2に配置すること。上下の二つずつと中央の一つで、絵本の見開きに空いた穴のような構図を作ります。縦一列の札も新聞の体裁も使わず、文字が色面から浮かびます。穴は入口の比喩で、物語の分岐ではありません。

### 一巡

開始はレモン色の面に大きな穴を一つ。「ことばを 5つ えらんで ニュースを つくろう」と「はじめる」を表示します。タップで前の選択・音声エラーを消して「だれが」へ。問いの下に、重複しない無作為の5候補が現れます。この段階中は候補も位置も固定します。

「ねこ」を押すと穴の縁が白く太くなり、内側に丸印が付きます。選択は保持され、確定ボタンなしで次へ。指が離れる前の連打を次の選択へ持ち越しません。上の進行窓は、選択済みを丸印、現在を太枠、残りを細枠で示します。「だれが→いつ→どこで→なにを→どうした」の順は固定です。

「きのう」「こうえん」「りんご」「たべる」と選ぶと、5つが揃った時点で、濃紫の大きな窓に「ねこが／きのう／こうえんで／りんごを／たべました！」が現れます。実表示はスラッシュを入れず語のまとまりで改行。「ニュースです」に続けて全文を自動再生します。全文は音声を待たず表示します。読みのまとまりに横線を添える表現も考えられますが、音声との厳密な同期は必須にせず、静止した区切りだけでも成立させます。「きく」は同じニュースを繰り返し再生。「もういちど」は音声を止め、選択を消し、候補を再抽選して最初へ戻ります。正誤や制限時間は設けません。

### 色・文字・視覚

#F4F03Bは全面背景、#30204Dは穴と本文、#FFFDF5は穴内の文字と受理の縁、#D84238は完成時の小さな句点風の印、#32705Aは進行済みの印に使います。赤や緑だけで状態を伝えません。文字は日本語ゴシックで、問い28px、候補22px、完成26pxを起点に。回転文字や穴に沿う文字は使わず、すべて水平に置きます。穴は少し非対称でも、文字領域は一定に確保します。

候補は高さ80px以上を起点とし、長い語では穴ごと縦に伸ばします。2・1・2の順とDOMの読み順を揃え、320px幅でも文字を折り返し、省略しません。縦スクロールを許容し、低い横画面や1024×600でも全文と主要操作に到達させます。セーフエリアを空け、キーボードの枠も見えるようにします。

### 音なし・読みの補助

必須素材は問いの5マークと穴の形だけ。364語の専用絵は要求せず、絵のない語にも同じ大きさの穴と文字を与えます。問いマークと5段の進行で操作を補助し、語の意味を読むのが難しい場合は保護者が読み添えます。音なしでも受理・進行・完成が分かり、動きを減らす設定では静止した輪郭変化だけで示します。

### 設定とエラー

「おとな」からスクロール可能な設定を開きます。標準はブラウザー音声、任意でモデル方式。方式、モデルフォルダー、声JSONは保存時だけ適用し、取消・閉じる・Escapeで編集を破棄します。ゲーム状態を保持し、背景操作を止め、閉じると入口へフォーカスを戻します。入力の書式不備と取得失敗は項目別に理由を示します。

音声は「じゅんび中」「よんでいるよ」を文字でも示し、再生中の重複起動を抑制。失敗時は一度だけ「こえが でなかったよ。ニュースは できたよ」と伝え、可能なら再生を再試行できます。完成表示と再スタートは止めません。オフライン・復帰も表示に反映します。

### 要件グループと未検証点

U・Gは5候補と一タップ進行、Wは短いラベルと助詞付き全文・読み・過去形の区別、S・Cは音声と設定で対応。Aは可変高、スクロール、フォーカス、音に依存しない状態表示です。新しい問いと完成へフォーカスを移し、初回と設定中は奪いません。P・Oの文字ゲームのオフライン、PWA、更新、解析・公開・許諾条件を維持し、説明は保護者側へ。Dの音声確認は通常の遊びから独立させます。

Vでは読みの習熟度×音の有無、対象ブラウザーと実機を分けて確認します。中央の候補へ注意が偏ること、強い色で疲れること、長語で穴の印象が崩れることが弱点候補です。観察前に「子どもが選びやすい」とは断定しません。

### 静止画UIモックアップ指示

スマホ2枚を横並びに描く。左は全面レモン色、濃紫の大きな穴を2・1・2に配置し、上から左→右→中央→左→右の順で、ねこ・いぬ・うさぎ・おばけ・ロボットの5候補を全部表示。問いは「だれが？」、上に進行1/5。候補の字は白く水平で、穴は少し非対称にする。右は濃紫の大窓に「ニュースができた」、共通例「ねこが きのう こうえんで りんごを たべました！」の全文を白い大きな文字で表示し、下に「きく」「もういちど」。紙、新聞、小鳥、立体カードは描かず、平らな強い色面と余白で構成する。

実装・テスト・実機と対象児の確認は未実施。未制作語の理解には保護者補助が残ります。

## 初稿

案名は「しろいページの とくべつごう」。一言の遊び心地は「ことばをひとつ見つけるたび、まっしろなページが自分のニュースになる」です。絵本の一ページのように、広い余白と小さな挿絵、大きな言葉を置きます。

開始画面には、文字のない一枚の紙と「ことばで ニュースを つくろう」、大きな「はじめる」。タップすると前の選択と音声エラーを消し、「だれが」に進みます。候補は縦に5枚並ぶ細長い紙片。一枚全体がボタンです。「ねこ」を押すと輪郭が太くなり、丸印が付き、すぐ次の問いへ移ります。連打は最初の一回だけ採用。候補は各段階で重複なしの5語を抽選し、その段階中は固定します。

以後「いつ→どこで→なにを→どうした」。上の5つの小窓は、選択済みを塗りつぶし、現在位置を太枠にします。「きのう」「こうえん」「りんご」「たべる」と選ぶと、最後に「ねこが／きのう／こうえんで／りんごを／たべました！」が現れます。スラッシュは説明上の区切りで、実画面では語のまとまりで改行。「ニュースです」に続く自動音声とともに、5つのまとまりを順に縁取りします。音なしでも全文は最初から読めます。「きく」で同じ全文を再生。「もういちど」で前の音声を止め、選択を消し、候補を再抽選して「だれが」へ戻ります。

色は紙の#FFF9ED、文字と枠の#263A35、選択済みの#356F63、受理印の#A94B37、装飾の#E9BC58の5色。黄は判別の唯一の手掛かりにしません。文字は丸みのある日本語ゴシック。問い28px、候補22px、完成文26px、補助文16px程度を起点に、実機で調整します。影や立体ボタンを使わず、手描きの細い枠と、紙の隅の小さな鳥で統一します。

必須の絵は5種類の問いマークと、開始・完成の小挿絵だけ。364語すべての絵は前提にしません。絵がない語も同じ寸法と重みで表示し、空白の画像枠は出しません。問いマークは「何を選ぶか」を補助しますが、各語の意味まで伝えるとは限りません。読みが難しい子には保護者の読み添えを想定します。太枠、丸印、進行窓、完成の見出しが音の代わりになります。動きを減らす設定では静止表示に置き換えます。

設定は紙の外側の「おとな」から開きます。音声方式、モデルフォルダー、声JSONだけを編集し、標準はブラウザー音声。保存だけが適用され、取消・閉じる・Escapeは変更を破棄。初期値へ戻しても保存までは未反映です。ゲーム状態を保持し、背景操作を止め、閉じると入口へフォーカスを戻します。保存・取消もスクロールで到達可能に。パスの不備は項目直下へ理由を表示し、書式と取得失敗を分けます。

読み上げ待機は「こえを じゅんび」、再生中は「きいているよ」と表示して重複再生を止めます。失敗時は一度だけ「こえが でなかったよ。ニュースは できたよ」。再試行可能なら「きく」を戻し、もう一度は常に使えます。通信状態は文字と印で知らせ、保存済みならオフラインでも文字の遊びを続けます。

要件グループとの対応は、U・G＝開始から繰り返しまでと5段階の選択、W＝短い候補と助詞付き全文の区別・読み・過去形の維持、S・C＝音声状態と設定です。Aは44px以上の候補、縦スクロール、キーボード操作に対応。候補は最小64px高を起点に可変高とし、長い語を省略せず折り返します。新しい問いと完成へフォーカスを移し、初回や設定編集中は奪いません。320px縦、667×375横、1024×600でも全文と操作へ到達させます。

P・Oのオフライン、PWA、更新、解析・許諾・公開条件を維持し、説明は保護者向け入口へ置きます。Dは子どもの動線から独立。Vは読みの習熟度×音の有無と実機で、理解、迷い、誤タップ、再遊びを観察します。長文では完成ページが縦長になるため、文章の下にも主要操作を置きます。
