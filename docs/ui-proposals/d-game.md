## 第2稿

案名：あわのうみのニュース

ひとことで遊び心地
海に浮かぶ五つの泡から、気になった一つをつつく。選ぶたびに海の景色が少し変わり、最後に言葉がつながって大きなニュースの泡になる。「次の海では何を選ぼう」と思えるかを確かめたい案です。

開始→5段階選択→完成→次ゲーム
開始画面は濃い青緑の海。小さなエイが、五つの泡が一つの大きな吹き出しになる絵を見せます。中央の「つくる」を押すと「だれが？」の海へ。候補は上2・中央1・下2の五つの泡で、視線を小さく巡らせられる配置です。全候補を同じ大きさ・明るさにし、正解に見える泡は作りません。

共通例では「ねこ」を1回タップ。泡が少しへこみ、輪が広がると同時に「いつ？」へ進みます。「きのう」→「こうえん」→「りんご」→「たべる」と選び、順番は常に「だれが→いつ→どこで→なにを→どうした」です。各回は重複のない無作為の5候補。同じ段階では変えず、新しいゲームで再抽選します。

選択中の泡だけに太い輪を付け、上部の五つのしるしが一つずつチェックに変わります。最初の入力だけ採用し、指を離すまで次の候補は受け付けません。確定ボタンは置かず、波紋も待たせません。次の問いを画面上部へ戻し、問いにフォーカスを移します。

五つ目を選ぶと、周りの泡が中央へ寄り、大きな「ニュースの泡」が現れます。「ねこが、きのう、こうえんで、りんごを、たべました！」を全文表示し、「ニュースをおしらせします」に続け、五つのまとまりを順に自動読み上げ。「きく」で同じニュースを繰り返し聞けます。「もういちど」で前の音声と選択を消し、新しい「だれが？」へ。景色の変化は現在の一巡だけです。

スマホの短いワイヤー
ねこ以外は説明用仮候補。原本への追加ではありません。

```text
[あわのうみ]       [おとな]
[●だれ ○いつ ○どこ ○なに ○どう]
            だれが？
   (絵 ねこ)       (絵 いぬ)
          (絵 ロボット)
   (絵 おばけ)     (絵 うさぎ)
       ～～ 海の底 ～～
```

```text
[✓ ✓ ✓ ✓ ✓]       できた！
     ╭ ニュースの泡 ╮
     │ねこが、きのう、│
     │こうえんで、    │
     │りんごを、      │
     │たべました！    │
     ╰───────────╯
  [▶ きく]  [↻ もういちど]
```

見た目
海#063B4C、泡#FFFFFF、波紋#2EE6C5、主操作#FF7E6B、現在地#FFE17C、遠景#8468E8の6色。候補と完成文は白地に海色の文字で、透明感は外側の輪だけに使います。ひらがな中心の丸ゴシック系システム書体、候補24px、本文22pxを起点にします。波打つ上辺、丸いエイ、二重の泡輪で世界観を統一。派手な背景模様は文字の後ろに置きません。

音なし・読みに不慣れな子
問いには人物・時計・場所・もの・動作の共通絵、候補にはふりがなと意味の補助絵を添えます。絵は海の生き物への置き換えでなく、その語のヒントです。問い用5種と操作用の絵をまず制作し、候補絵は描ける語から共通部品で整備。全364語の専用絵が完成済みとは想定せず、素材のない語も同じ寸法のひらがな付き泡で扱います。補助の必要性は観察対象です。波紋、チェック、問いの交代、全文出現があるため、音は進行の唯一の合図にしません。

高度設定・エラー
隅の「おとな」から音声設定を開き、遊びの背景操作を止めます。標準はブラウザー日本語音声、任意でSupertonic・モデルフォルダー・声JSON。保存だけが適用で、取消・閉じる・Escapeは編集を破棄し、初期値に戻す操作も保存待ち。ゲーム内容は保ち、閉じたら入口へフォーカスを戻します。ラベル、項目別エラー、入力欄への移動、縦スクロールを用意し、書式不正と取得失敗を区別します。

完成は音声を待たず、準備中・再生中を文字と記号で表示。重複再生を抑え、停止・失敗後は操作可能に戻します。失敗は一度だけ「おとは おやすみ。ニュースは できたよ」と伝え、可能なら再試行。次ゲーム・設定変更・終了では古い音声を止めます。

要件グループとの対応
U・Gは五つの泡、固定5段階、1タップ進行、評価なしの一巡に対応。Wは全364語、候補と完成の表記・読みの区別、助詞と丁寧な過去形、文末「！」を維持。長い語は泡を縦に伸ばして折り返し、全文と主要操作には縦スクロールで到達できます。S・Cは上記に加え、設定復元・不正値の既定化・保存不可時の継続、指定のパス検証と方式の無断切替禁止を守ります。

Aは320px縦、667×375横、1024×600を含め、泡を重ねず当たり判定44px以上、見えるキーボードフォーカス、横あふれ防止を優先。低い画面では縦にスクロールし、セーフエリアを確保します。動きを減らす設定では位置の移動を消し、輪とチェックを残します。画像失敗でも文字で完走可能。P・Oはオフライン文字ゲーム、通信表示、PWAと版を揃えた更新、個別内容を送らない解析方針、説明・権利・メタ情報・静的配信を保持。Dの語彙音声確認・指定結果・実モデル確認は子どもの経路から外します。Vは読字習熟×音の有無、失敗とオフライン、対象ブラウザーを自動確認と実機に分けて検証します。

弱点と後で確かめること
中央の泡へ選択が偏らないか、丸い候補で長語が読みにくくならないか、抽象語にどれだけ大人の補助が要るかが弱点です。誤タップと迷い、完成時の反応、自発的な再挑戦を観察し、泡の間隔・ヒント・動きの時間を調整します。楽しさの成立は未検証です。

静止画モックアップ指示
縦長スマホ2枚を横並び。濃い青緑の海に白い二重輪の泡、ミント色の波紋、黄色の現在地、小さな紫の遠景、丸いエイ。左は「だれが？」と進行5しるし。ねこ・いぬ・ロボット・おばけ・うさぎの全5候補を、上2・中央1・下2の泡に大きく配置。ねこ以外は説明用仮候補。右は大きな白いニュースの泡に「ねこが、きのう、こうえんで、りんごを、たべました！」を全文表示し、「きく」「もういちど」を下に置く。両画面に小さな「おとな」。紙、機械、点数、宝箱、収集物は描かない。

## 初稿

案名：ぽん！ことばプリント

ひとことで遊び心地  
五つの言葉をぽん、ぽんと印刷機に入れると、自分にも予想できない一枚のニュースが出てくる。選ぶ手応えと最後の「そうつながるの？」が、繰り返しの動機になるという仮説です。

具体的な一巡  
開始は空の印刷機と「ニュースを つくる」の大きなボタン。五つの部品が一枚になる絵で遊びを伝えます。押すと「だれが？」と縦一列の5候補。例の「ねこ」を選ぶと、カードが小さく沈み、ねこの文字が機械の一つ目の窓に入ります。同時に「いつ？」へ進みます。「きのう」→「こうえん」→「りんご」→「たべる」と、必ず「だれが→いつ→どこで→なにを→どうした」の順で1回ずつ選びます。各段階は重複のない無作為の5候補で固定し、次ゲームで再抽選します。

追加の確定ボタンはありません。最初のタップだけ採用し、指が離れるまで次の候補を受け付けません。短い印刷動作を待たずに次の問いを読めます。上部の五つの窓は、済んだ窓にチェック、現在の窓に太枠を付けます。数字だけ、色だけには頼りません。

五つ目で紙が短くせり上がり、完成文「ねこが／きのう／こうえんで／りんごを／たべました！」を全文表示。自動で「ニュースをおしらせします」に続けて五つのまとまりを順番に読みます。「きく」は同じ文の再生、「もういちど」は音声と選択を消して、新しい5候補の「だれが？」へ直行します。採点や報酬は付けません。

スマホの短いワイヤー  
選択例のねこ以外の4語は配置説明用の仮候補で、語彙への追加は意味しません。

```text
[ぽん！ことばプリント]
[●だれ][○いつ][○どこ][○なに][○どう]
           だれが？
[ 小さな絵   ねこ       ]
[ 小さな絵   いぬ       ]
[ 小さな絵   ロボット   ]
[ 小さな絵   おばけ     ]
[ 小さな絵   うさぎ     ]
                [おとな]
```

```text
[✓][✓][✓][✓][✓] できた！
┌──────────────────┐
│ねこが、きのう、           │
│こうえんで、りんごを、     │
│たべました！               │
└──────────────────┘
[▶ きく]    [↻ もういちど]
[おとな] [プライバシー]
```

見た目  
背景#FFF6DF、本文#283342、紙#FFFFFF、主操作#FF765C、完了の枠#2D6A63、進行の窓#F4CF57の6色。色面には濃い文字を置きます。丸ゴシック系のシステム書体、本文22px、候補24pxを目安にします。候補は高さ64px以上、間隔8px。印刷の切り欠き、丸い押印、アイコンの線幅を統一し、紙の質感は薄く、文字の背後は平面にします。

音なし・読みに不慣れな子  
問いには人物・時計・場所・もの・動作の五つの共通絵、文字にはふりがな。候補の補助絵は人物や物から制作し、共通部品を組み合わせます。全364語の専用絵が完成済みとは想定しません。絵がない語もひらがなの文字カードで選べ、空枠にはしません。絵だけで抽象語まで理解できるとは扱わず、必要な補助を観察します。選択の沈み、チェック、問いの交代、完成紙で、無音でも操作の結果が分かります。

高度設定・エラー  
「おとな」から独立した設定パネルへ。標準はブラウザー日本語音声、任意でSupertonicとモデルフォルダー・声JSONを設定します。変更は保存時だけ適用し、取消・閉じる・Escapeは破棄。初期値への復帰も保存待ちです。ゲームは保持し、背景操作を止め、閉じたら入口へフォーカスを戻します。入力欄にラベルと項目別エラーを置き、URL書式不正と取得失敗を区別します。狭い画面ではパネル内をスクロールできます。

完成文は音声を待ちません。「おとを じゅんび中」「よみあげ中」は口の記号と文字で表示。再生中は重複再生を受け付けず、失敗なら一度だけ「おとが でないよ。ニュースは できているよ」と表示して再試行可能にします。設定変更・次ゲーム・終了で古い音声を止めます。

要件グループとの対応  
U・Gは、固定の5段階×5候補、1タップ進行、評価なしの印刷遊びで対応。Wは全364語を維持し、候補表記と助詞付き完成表記、読みを分離、対応表で丁寧な過去形と「！」を生成。長い文は折り返して縦スクロールし、主要操作にも届きます。S・Cは上記の音声と設定に加え、保存値の復元・不正値の既定化・保存不可時の継続、指定されたパス検証を保ちます。

Aは320px縦・667×375横・1024×600を含め、横あふれを防ぎ、タッチ下限44px、キーボード操作、見えるフォーカス、問いへのフォーカス移動を用意。セーフエリアと動きを減らす設定に対応し、画像失敗でも文字ボタンを残します。Pは初回保存後のオフライン文字ゲーム、通信状態表示、PWAと版を揃えた更新を保持。Oは言葉や識別子を送らず、本番の標準beacon以外を追加せず、説明・権利・メタ情報・静的配信を新意匠に整合します。Dの語彙音声確認、指定結果、実モデル確認は子どもの導線から外します。Vでは読字習熟×音の有無、失敗・オフライン、対応ブラウザーを、自動確認と実機を分けて検証します。

弱点と後で確かめること  
印刷機の比喩が伝わるか、候補の絵が意味を誤らせないか、次の問いの即時切替で迷わないかは未確認です。誤タップ、選び終えた満足、完成への反応、自発的にもう一度押す様子を観察し、寸法と演出時間を調整します。

静止画モックアップ指示
