## 第2稿

### 案名：かたちの ニュースこうじょう

遊び心地は「大きな積み木を、ぽん、と選んでニュースを組み立てる」。木製玩具を手掛かりに、丸、半円、四角、ひし形、階段形を使う。青緑の大きな面に黄や赤を置き、形の輪郭を見せる。五形が揃う喜びと文章の面白さへの効果は未検証である。

開始は五形と「ことばを ５こ えらぼう」「はじめる」を表示する。開始で前回の選択と音声エラーを消し、①だれが、②いつ、③どこで、④なにを、⑤どうしたへ進む。各段階の五候補を、二列・二列・中央一個の同寸の積み木として並べる。一候補をタップしたら輪郭とチェックで受け付けを示し、そのまま自動で次へ。候補はその段階では固定し、新しいゲームで重複なく再抽選する。

上部の五形は現在の形には太い下線、済んだ形にはチェックと番号を付ける。新しい問いへフォーカスを移す。連打も最初の一候補だけを採用。選択後に小さく沈む表現を添えても、演出待ちや追加の確定操作は設けない。

五つ目で「ニュース できた！」と全文を表示する。「ねこが／きのう／こうえんで／りんごを／たべました！」を、語のまとまりごとに改行する。各行に対応する形を添え、選択順と結び付ける。自動読み上げは「ニュースこうじょうから おしらせです」に続いて全文を区切って読む。「きく」で繰り返し再生。「もういちど」で音声と選択を消し、新しい「だれが」へ戻る。

```text
┌──────────────────┐
│ かたちのこうじょう 設定│
│ ○１ ◐２ □３ ◇４ ▰５│
│ ━━                │
│ だれが？           │
│ ┌──────┐ ┌──────┐ │
│ │ ねこ │ │候補２│ │
│ └──────┘ └──────┘ │
│ ┌──────┐ ┌──────┐ │
│ │候補３│ │候補４│ │
│ └──────┘ └──────┘ │
│     ┌──────┐      │
│     │候補５│      │
│     └──────┘      │
└──────────────────┘

┌──────────────────┐
│ ニュース できた！ │
│ ○ ◐ □ ◇ ▰        │
│ ○ ねこが          │
│ ◐ きのう          │
│ □ こうえんで      │
│ ◇ りんごを        │
│ ▰ たべました！    │
│ [きく]            │
│ [もういちど]      │
└──────────────────┘
```

候補２〜５は仮ラベル。実際は異なる言葉を抽選する。五候補は同じ寸法と色にする。

六色は、背景と濃い文字の深青緑 **#20343B**、明るい文字と選択印の白 **#F7F5ED**、候補の面の黄 **#E5B84B**、形の差し色の赤 **#B94432**、緑 **#39766F**、完成文の面の水色 **#AFC9CB**。黄と水色には深青緑、赤と緑には白を合わせる。標準ゴシックで、候補22px、質問と完成文24pxを出発点にする。候補は高さ80px以上、間隔12px。長い語では高さを増やし、文字を切らない。

音なしでも、チェック、問いの交代、進捗、完成文で操作が分かる。形と番号を併用し、色当てを要求しない。五形は段階を覚える手掛かりで、各語の意味を表す絵ではない。制作は五形とロゴ程度。全語の専用絵や新しい読み支援機能を前提にしない。読めない候補の意味には大人の読み添えが必要になり得る。時間制限、正誤の評価、点滅、常時動く装飾は置かず、動きを減らすOS設定では静止した選択印だけで伝える。

設定は上端から開く。音声方式、モデルフォルダー、声JSONと、保存・取消・初期値を配置する。保存前は未適用、閉じる・取消・Escapeで編集を破棄し、ゲーム内容は保持する。背景操作を止め、閉じたら入口へ戻す。保存値を復元し、入力書式と取得失敗を区別する。保存不可でも継続できる。

音声準備中や失敗時も全文と次ゲームへの操作を使える。再生中は重複を防ぎ、失敗は「こえが でなくても あそべるよ」と示す。方式の無断切替はしない。320px幅でも二列を基本とし、長文と低い横画面は縦スクロールで全文と操作へ到達させる。キーボード、見えるフォーカス、セーフエリアに対応する。

要件対応は、U・Gが五候補と五段階の反復、Wが全語彙と候補・完成・読みの区別、S・Cが完成を妨げない音声と設定、Aが折り返しと複数の状態手掛かり。Pでは五形も含め文字のゲームを初回保存後に使えるようにする。O・Dの公開条件と開発者用機能を守り、遊びの導線には混ぜない。Vに沿って実際の子どもと端末で検証する。

弱点は、形の対応を覚える負担と、中央の五候補目が目立つ可能性。読みに習熟した子と難しい子、音あり／なしで、候補の意味理解、視線の偏り、誤タップ、補助の量、再び遊ぶ意欲を観察する。横画面、長文、音声失敗、オフラインも確認する。実装・テストは今回行わず、寸法と楽しさは未検証。

### 静止画モックアップ指示

スマホ縦画面二枚を横並びにする。深青緑を背景の主役に、黄、赤、緑、水色の大きな幾何学形を配したミッドセンチュリー玩具の意匠。左は「だれが？」、五段階の形と番号、黄の同寸積み木五候補を二列・二列・中央一個に配置。「ねこ」「候補２」「候補３」「候補４」「候補５」を全部見せる。右は水色の広い面に「ねこが／きのう／こうえんで／りんごを／たべました！」の全文と五形、大きな「きく」「もういちど」。白い縦札、布、生成り主体、光沢、点滅は使わず、輪郭と文字を明快に。

## 初稿

### 案名：もこもこ ことばびん

遊び心地は「ことばのクッションを、ぽん、と選んで届ける」。丸い布の輪郭と小さな縫い目で、触りたくなる穏やかな楽しさを作る。派手なごほうびや音量で盛り上げず、選んだ五つが一枚のおかしな通信になる変化を見せる。楽しさや安心感への効果は、子どもの観察前の仮説である。

開始画面には五つの小さな布片と、完成した通信の形を並べ、「ことばを ５こ えらぼう」「はじめる」を置く。説明を閉じる操作や練習は挟まない。開始すると前回の選択と音声エラーを消し、①だれが、②いつ、③どこで、④なにを、⑤どうしたの順に進む。毎回、重複しない五候補を提示する。候補は同じ段階にいる間は変わらない。

どの段階も、候補を一回タップすると輪郭が濃くなり、チェックが付き、そのまま次の問いになる。上部の五つの縫い目にもチェックが一つ増える。動かす場合も短い沈み込み程度とし、演出終了を待たせない。押し続けや連打は最初の一候補だけを受け付ける。新しい問いを画面上部に出し、フォーカスもそこへ移す。

五つ目で完成通信を直ちに表示する。共通例は「ねこが／きのう／こうえんで／りんごを／たべました！」。語のまとまりごとに柔らかな下線を添え、一つの文章として順に読める。自動読み上げでは「ことばびんの ニュースです」に続けて全文を知らせる。「きく」で同じニュースを何度でも再生でき、「もういちど」で音声と選択を消し、新しい五候補の「だれが」へ戻る。

```text
┌──────────────────┐
│ もこもこ       設定│
│ ✓ · · · ·  １／５ │
│ だれが？          │
│ ┌──────────────┐ │
│ │ ねこ          │ │
│ └──────────────┘ │
│ │ 候補２        │ │
│ │ 候補３        │ │
│ │ 候補４        │ │
│ │ 候補５        │ │
└──────────────────┘

┌──────────────────┐
│ ニュース できた！ │
│                  │
│ ねこが           │
│ きのう           │
│ こうえんで       │
│ りんごを         │
│ たべました！     │
│                  │
│ [きく]           │
│ [もういちど]     │
└──────────────────┘
```

候補２〜５は配置説明用の仮ラベル。実際は語彙から抽選した別々の言葉を表示する。

色は六色に絞る。背景は生成り **#FFF8EC**、本文と輪郭は濃紺 **#253247**、選択できる布面は白 **#FFFFFF**、受け付けた印は深緑 **#266653**。薄桃 **#F2D0CA** と水色 **#CCE5EA** は布端や見出し周辺の装飾に使い、小さな文字を載せない。状態は色に加えて輪郭、チェック、言葉でも示す。書体は日本語の丸ゴシック系を端末の標準フォントで構成し、候補は原則22px、本文は22〜24px。候補は同じ幅の一列で、高さ56px以上、間隔8pxを出発点とする。長い語は折り返して高さを増やし、切り詰めない。

音なしでも、押した印、質問の交代、進捗、完成見出しで一連の変化が分かる。正解色、順位、カウントダウンは設けない。五種類の質問には、小さな顔、昼夜、場所、物、動きの共通記号を添える。制作する絵はこの五記号とロゴ程度で、364語の専用イラストは前提にしない。記号は「何について選ぶか」の補助であり、各候補の意味を説明したことにはしない。読めない子には、大人の読み添えが残る。文字だけで全語を自立して理解できるとは主張しない。

常時揺れる装飾、点滅、画面を覆う紙吹雪は使わない。OSの動きを減らす設定では、沈み込みもチェックの静止表示に置き換える。音や動きを好む子にも、触れた手応えと完成した布面の変化で楽しさを作れるかを試す。感覚刺激を調整する新しいモードや設定項目は増やさない。

「設定」は遊びの候補から離して配置するが、小さすぎる入口にはしない。中は保護者向けの文字中心のダイアログとし、音声方式、モデルフォルダー、声JSON、保存、取消、初期値へ戻すを扱う。保存までは変更を適用せず、閉じる・取消・Escapeで編集を破棄する。ゲームは保持し、閉じたら入口へフォーカスを戻す。入力の書式エラーは該当欄の近くに理由を示し、取得失敗とは区別する。

音声準備中も完成文と「もういちど」は使える。再生中の「きく」は重複起動を防ぎ、失敗時は同じ場所に「こえが でなくても あそべるよ」と一度示す。別方式へ勝手に切り替えない。通信断も控えめな状態表示にとどめる。長い完成文や低い横画面では縦スクロールを許し、主要操作へ到達できる構造にする。初回や設定中にはフォーカスを奪わない。

要件グループへの対応は、U・Gが「五候補、一タップ、五段階、評価なしの反復」、Wが「全364語と候補・完成・読みの区別」、S・Cが「完成を妨げない音声と独立した設定」、Aが「折り返し、十分な領域、キーボード、静止した状態表示」。Pでは文字のゲームと新しい軽量素材を初回保存後も使える設計にする。O・Dのプライバシー、公開条件、開発者用導線は外観変更で崩さず、通常の遊びへ持ち込まない。Vに従い、音なし・読みの差・実機で確認する。

弱点は、布の意匠だけでは候補の意味理解を支えきれないこと。試作後は読みに習熟した子と難しい子について、音あり／なしで迷い、誤タップ、大人の補助、完成への反応、再び遊ぶ意欲を観察する。320px縦画面、667×375px横画面、1024×600px、長文、音声失敗、オフラインも確認する。今回は実装・テストを行っておらず、寸法と楽しさは未検証である。

### 静止画モックアップ指示

スマホ縦画面を二枚、同じ大きさで横並びにする。生成り背景、濃紺の太めの文字、白い布のクッションを思わせる角丸カードと控えめな縫い目。左は「だれが？」と進捗１／５、「ねこ」「候補２」「候補３」「候補４」「候補５」の五候補をすべて一列に表示。右は「ニュース できた！」と「ねこが／きのう／こうえんで／りんごを／たべました！」の全文、その下に大きな「きく」「もういちど」。桃色と水色は布端の装飾に限定。小さなスマホでも読める文字量と広いタップ領域を優先し、紙吹雪や派手なキャラクターは加えない。
