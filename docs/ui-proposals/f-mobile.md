## 第2稿：ことばの せんすいかん

### 遊び心地一言

親指で五つのスイッチからひとつ選ぶと、上の大きな窓に光が増え、最後にニュースが浮かび上がる。

### 開始→五段階→完成→もう一度

開始は広い海中窓と「ことばを５こ えらぼう」、下に「はじめる」。押すと窓に顔のマークと「だれが？」を出し、下部の五候補を一斉に使える状態にする。

「ねこ」を一回押すと、そのスイッチの輪郭が太くなり、窓の一灯目が点く。「いつ？」へ自動で切り替わり、続けて「きのう」→「こうえん」→「りんご」→「たべる」を選ぶ。配置は変えず、問いは「だれが→いつ→どこで→なにを→どうした」の順。候補は各段階で無作為に五つ出し、その段階中は固定。次ゲームで再抽選。最初の一押しだけを受け付け、指を離す前の入力や連打を次段階へ持ち越さない。

五灯目が点くと、窓全体が明るくなり「ねこが／きのう／こうえんで／りんごを／たべました！」を全文表示。「ニュースを おつたえします」に続いて自動で読み上げる。下の操作盤は「きく」「もういちど」の二領域へ変わる。再生中の重複起動を抑え、「もういちど」で古い音声と選択を消し、新しい「だれが？」へ進む。時間制限や正誤判定は置かない。

### 配置とスマホワイヤー

五候補を上三つ・下二つの浅い二段にする。通常は下部約180pxに収め、上部には大きな表示窓を残す。各領域は高さ72pxを起点、間隔8px以上。長語は縮小せず折り返して伸ばす。

②〜⑤は原本未提示のため仮表記。実装時は既存語彙を入れる。

```text
┌────────────────────┐
│ せんすいかん    設定 │
│ ╭────────────────╮ │
│ │ ● ○ ○ ○ ○ １/５│ │
│ │                │ │
│ │    ☺ だれが？   │ │
│ │                │ │
│ │ ひとつ おしてね │ │
│ ╰────────────────╯ │
│ ┌────┐┌────┐┌────┐ │
│ │ねこ││候補②││候補③│ │
│ └────┘└────┘└────┘ │
│   ┌──────┐┌──────┐ │
│   │候補④ ││候補⑤ │ │
│   └──────┘└──────┘ │
└────────────────────┘
```

```text
┌────────────────────┐
│ せんすいかん    設定 │
│ ╭────────────────╮ │
│ │     できた！    │ │
│ │ ねこが         │ │
│ │ きのう         │ │
│ │ こうえんで     │ │
│ │ りんごを       │ │
│ │ たべました！   │ │
│ ╰────────────────╯ │
│  こえを よんでいるよ │
│ ┌──────┐┌────────┐ │
│ │ きく ││もういちど│ │
│ └──────┘└────────┘ │
└────────────────────┘
```

長い完成文は上部窓内を縦にスクロールでき、下部操作と重ねない。低い横画面は全体を縦スクロールする。320px幅でも文字を横にはみ出させず、セーフエリアを空ける。

### 見た目

主調色は深海の **#102B46**。文字は **#ECF8FF**、操作盤は **#123F52**、受け付けた選択は **#56D6C9**、完成の光は **#FFD269**、エラーは **#FF9C98**。日本語ゴシックで候補20px、完成24px程度を起点にする。広い丸窓と、下に集まる五つの発光スイッチが目印。

### 音なし・読むのが難しい子

進行は五灯と数字、選択は輪郭、完成は窓の明度と文字でも示す。減らす動きの設定では明滅を使わず即座に状態を変える。新規素材はカテゴリ五種と共通例の意味絵から試作し、全364語の専用画像を前提にしない。絵のない語も省略せず、保護者が読み添えられる。カテゴリ絵だけで各語の意味が分かるとは断定しない。

### 設定とエラー

上端の「おとなのせってい」に音声方式・モデルフォルダー・声JSONをまとめる。遊びを保ったまま開き、保存時だけ反映。取消・閉じる・Escapeは編集を破棄し、背景操作を止め、終了後は入口へフォーカスを戻す。入力エラーは項目と理由、取得失敗は通信状態として区別する。音声失敗は一度だけ知らせ、完成文と再試行可能な「きく」を残す。

### 要件グループへの対応

U/Gは開始、固定五候補、順序、自動進行、再遊びを上記の一巡で扱う。Wは全364語を保持し、候補の短表記と助詞付き完成表記、読み、動作変換を分ける。S/Cは標準の日本語音声、任意モデル、保存と取消、設定復元と入力検証を維持する。Aはキーボード完走、フォーカス表示と移動、画像失敗時の操作を保つ。Pはブラウザー内動作、保存後のオフライン文字遊び、PWAと整合した更新を維持する。Oは選択内容を解析へ送らず、許諾・説明・公開情報を新テーマに揃える。Dの音声確認と指定結果表示は通常導線から外す。Vは対象児の観察、自動確認、実機確認を区別する。

### 弱点と確認項目

上三つは幅が狭いため、長語では操作盤が縦に伸びる。左右の片手操作で五領域への届き方、親指による文字の隠れ、誤タップを確認する。音なし・読みの難しい子の理解、指定寸法・各ブラウザー・オフラインの完走も確認する。楽しさと適切な寸法は未検証。今回は実装しない。

### 静止画モックアップ指示

縦長スマホ二枚を横並びに描く。世界観は深い青緑の潜水艦。上部に広い丸窓、下部に親指で押せる発光スイッチを上三つ・下二つでまとめる。左は「だれが？」と進行１／５、五候補「ねこ」「候補②」「候補③」「候補④」「候補⑤」を全部表示。右は丸窓に「ねこが／きのう／こうえんで／りんごを／たべました！」を全文表示し、下に「きく」「もういちど」。深紺背景、淡い水色文字、青緑の選択光、黄色い完成光。紙面、札、スタンプを描かず、大きな表示窓と二段の操作盤の違いを明瞭にする。

## 第1稿：ことばの ぱちんスタンプ

### 案名：ことばの ぱちんスタンプ

遊び心地は「親指でひとつ押すと、ことばの跡が残り、最後に一枚のニュースになる」。五つの候補を毎回同じ位置に置き、押す楽しさと、完成の見た目の変化を中心にする。

### 開始から、もう一度まで

開始には空の紙と五つの薄いスタンプ跡。「ことばを５こ えらぼう」と、大きな「はじめる」を置く。設定は上端の「おとなのせってい」にまとめ、遊びのボタンと形を変える。

始めると「だれが？」と顔のマークが現れ、五候補を縦に並べる。「ねこ」を一度押すと、ボタンが浅く沈み、紙の一枠目に「ねこが」が押される。選択はその場で受け付け、装飾の終了を待たせず「いつ？」へ進む。

続いて「きのう」→「こうえん」→「りんご」→「たべる」を一回ずつ選ぶ。問いは「いつ→どこで→なにを→どうした」の順。上の紙には小さなスタンプ跡が一つずつ増え、「３／５」の数字と三つの塗りつぶしでも進行を示す。候補は毎段階五つすべてを扱い、一覧を横に送る操作は使わない。

最後の選択で五つの跡が大きな一枚の紙に変わり、「ねこが／きのう／こうえんで／りんごを／たべました！」が全文現れる。同時に「ニュースを おつたえします」に続く自動読み上げを始める。「きく」で同じ全文を再生でき、「もういちど」で音声と選択を消し、新しい五候補の「だれが？」へ直行する。

### スマホの構図

原本の候補一覧は資料にないため、②〜⑤は配置用の仮表記。実装時は既存語彙から抽選した語を置き、追加語にはしない。

```text
┌──────────────────┐
│ ぱちんスタンプ  設定│
│  ● ○ ○ ○ ○   １/５ │
│ ┌────────────────┐ │
│ │   ここに おせるよ │ │
│ └────────────────┘ │
│      ☺ だれが？     │
│ ┌────────────────┐ │
│ │      ねこ        │ │
│ ├────────────────┤ │
│ │      候補②       │ │
│ ├────────────────┤ │
│ │      候補③       │ │
│ ├────────────────┤ │
│ │      候補④       │ │
│ ├────────────────┤ │
│ │      候補⑤       │ │
│ └────────────────┘ │
└──────────────────┘
```

```text
┌──────────────────┐
│ ぱちんスタンプ  設定│
│      できた！       │
│ ╭────────────────╮ │
│ │ ねこが          │ │
│ │ きのう          │ │
│ │ こうえんで      │ │
│ │ りんごを        │ │
│ │ たべました！    │ │
│ ╰────────────────╯ │
│  こえを よんでいるよ│
│ ┌────────────────┐ │
│ │       きく       │ │
│ └────────────────┘ │
│ ┌────────────────┐ │
│ │    もういちど    │ │
│ └────────────────┘ │
└──────────────────┘
```

候補は画面の中央から下を使う、幅いっぱいの五段。通常は高さ56px以上、間隔8pxを出発点にする。次の問いでも位置を揃え、親指を探し直す負担を減らす。長い語は折り返して行を伸ばし、狭い縦画面や横画面では縦スクロールを許す。操作を隠す固定フッターは置かない。最初の一押しだけを採用し、指を離す前の入力や連打が次の段階へ漏れないようにする。

### 見た目

背景は紙のような **#FFF8E7**、文字と輪郭は **#203A39**。候補面は **#FFFFFF**、選択と進行は **#006C67**、完成の紙の縁は **#FFD46B**、エラーは **#B13D5D**。状態は色だけでなく、輪郭、文字、形の変化でも示す。

文字は読みやすい丸みのある日本語ゴシックを使い、候補は20px程度、完成文は24px程度を起点に調整する。記憶に残る特徴は、ボタンの下辺にある厚い「ゴムのふち」と、選ぶたびに増える少し不揃いなスタンプ跡。揺れや紙吹雪を常時動かさない。

### 音なしと読みの難しい子

押した候補に輪郭と印が付き、次の問いと進行が変わるため、操作音がなくても選択を確認できる。完成は紙の拡大と「できた！」で伝える。動きを減らす設定では、その最終状態を直ちに示す。

問いには人物、時、場所、物、動作を示す五種類の補助絵を新規制作する。共通例の意味絵も試作するが、全364語の専用画像がある前提にはしない。素材のない候補も文字を欠かさず表示し、初めは保護者が読み添えられる構図にする。カテゴリ絵だけで個々の語の意味まで理解できるとは考えず、自立して選べる範囲を対象児で確かめる。

### 設定とエラー、要件への対応

設定はスクロールできる大人向けダイアログ。ゲームの状態を保ち、保存時だけ音声方式・モデルフォルダー・声JSONを反映する。取消、閉じる、Escapeは編集を破棄する。入力の理由付きエラーと取得失敗を区別し、閉じたら入口にフォーカスを戻す。

U・G・Wでは、登録不要、固定された五候補、五段階、自動進行、全文表示を保つ。短い候補表記から完成文を単純連結せず、助詞、読み、過去形、末尾の「！」を維持する。S・Cでは標準音声と任意モデルを分け、無断で切り替えない。音声失敗時も完成を表示し、「こえが でないよ。もじで あそべるよ」と一度伝える。

A・Pでは見えるフォーカス、問いへの移動、セーフエリア、長文への到達を確保する。ブラウザー内の文字ゲーム、保存後のオフライン、PWAを保ち、通信状態は小さな文字で知らせる。O・Dでは選択内容を解析へ送らず、公開説明・素材許諾・アイコン類を新テーマに合わせる。音声確認と指定結果の開発機能は子どもの導線から外す。Vでは音の有無、読む力、指定画面寸法、実機音声を分けて確認する。

弱点は、五段の最上段が片手では届きにくい端末があることと、補助絵のない語の理解。左右の手で持った誤タップ、届き方、長語の折り返し、完成への反応、再遊びの意思を観察する。楽しさや最適寸法は未検証であり、実装とテストは今回行わない。

### 静止画モックアップ指示

縦長スマホ二枚を横並びに描く。テーマは「ことばの ぱちんスタンプ」。背景はクリーム、文字は濃緑、白い候補ボタンに厚いゴムの下辺。左は「だれが？」の選択画面。進行１／５と空の紙を上に置き、「ねこ」「候補②」「候補③」「候補④」「候補⑤」の五候補を省略せず縦に表示する。右は黄色い縁の大きな紙に「ねこが／きのう／こうえんで／りんごを／たべました！」を全文表示。下に大きな「きく」「もういちど」。小さな設定入口も両画面に統一して置く。日本語を明瞭にし、装飾より文字と押せる範囲を優先する。
