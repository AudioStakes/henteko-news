# UI案の静止画生成プロンプト

アプリや既存画面の画像を参照せず、各サブエージェントの提案を入力に静止イメージを作成した。
AからFの最終画像は `images/` に保存した。
画像は見た目の比較用であり、実装や操作の検証結果ではない。
